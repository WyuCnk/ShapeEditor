## 改动 1：路由加前置判断（最高优先级）

实测结论（3–7 层 4861 列交叉统计，见 §0.11.6）：

```
目标第 1 层是普通格 T  ⇒ 那枚格必须落到第 1 层 ⇒ d = 1
                        ⇒ 违反构造 H 的前提 2 ≤ d ⇒ 构造 H 做不到
```

**所以在进构造 H 之前先判：**

```csharp
if (column[0] == 'T') {
    // 不走构造 H（不要尝试、不要浪费时间）
    // 直接进：切割碎晶（构造 D/G）或 弱落（构造 E）
}
```

验收：`t[1]=='T'` 的列**不得**再出现「构造 H 失败后回退」的日志；
生成耗时应当下降。

## 改动 2：47 列改用「N 连续针段」规则，一次顶针

`residual-47-weakdrop.md` 里的 47 列目前走了弱落，但它们**都有一次顶针解**（4 个已实测）。

**前态生成规则（这一族）**：

```
A = 目标列的【晶体下移一格】，再按 P1 把晶体正下方补成普通格
B = cTTT..（第 1 层放晶体，其余普通格，到 BTop 为止）
E = 满高纯晶体柱
N = T P P … P T …     ← 针从 L2 起【连续】，个数 = 该列要下降的普通格数 + 1
```

**必须通过的回归（这些前态已实测 ✔，逐格回放）**：

| 目标 | A | B | E | N |
|---|---|---|---|---|
| `.TT.c` | `.TTc.` | `cTT..` | `ccccc` | `TPPT.` |
| `.T.T.c` | `.T.Tc.` | `cTTT..` | `cccccc` | `TPPPT.` |
| `.TTT.c` | `.TTTc.` | `cTTT..` | `cccccc` | `TPPPT.` |
| `.TT.Tc` | `.TTTc.` | `cTTT..` | `cccccc` | `TPPTT.` |

（用 `ShapePhysics.Pin` 回放，`col0` 必须逐格等于目标。注意 `N` 的短代码要按 cap 补齐。）

## 改动 4：弱落的工序写法（若仍出现）

每一步必须写全五项，缺一不可：

```
[PreState]  A 列当前形态；辅助列 S′：连续接地，仅第 s 层为针，其余普通格
[Support]   撤掉原托柱（只剩 A 与 S′）
[Collapse]  第 s 层的普通格（及其上方连续针链）下落，停在第 s′ 层
            必须写明：哪一格、落在哪一层的什么材料之上、跨了几层
[Support]   装回满高托柱
[PreState]  拆掉 S′
```

只写「弱落（构造 E）」不合格。
