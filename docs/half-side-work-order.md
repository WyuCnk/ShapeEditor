# 半边工序：非 S 合法角的处理（n = 4）

> 触发例：`cT.T.cPT`。**五项 ✔，D ✘，F ✘ ⇒ 合法但非 S**（定理 3 判单角不可制作）。
> 但它**确实能做**——必须与相邻象限一起做。
> 本文给出：现状判定、实测配方、设计选项，以及「论文算法 8 不完备」的证据。

---

## 1. 现状：角级判定是对的，缺的是「半边级」路径

```
cT.T.cPT   五项 ✔   D ✘   F ✘   S ✘
```

- **角级**：`AngleWorkOrderBuilder.Build` 报「不可制作：n = 4 的 S 判据不成立」——
  **这个判定是正确的**：按定理 3，n = 4 的 S 列必须满足 `五项 ∧ (D∨F)`；
  该列 D、F 都不成立 ⇒ 单角（带一根托柱）在数学上不可能。
- **缺口**：算法里没有「两列一起做」的入口。角级说「不可制作」，整图就放弃了,
  但这个半边其实是可得的。

---

## 2. 实测：这个角确实能做（用户配方，已验证）

```
第一象限  cTccTcPT        ← 目标列：临时晶体在 L3、L4，T 被提到 L5
第二象限  TTTcTccc        ← 环伙伴：顶部三层 L6/L7/L8 是 ccc，与第一象限咬合
第三象限  空
第四象限  TTTc            ← 保险丝柱：T,T,T,c（晶体在 L4，与临时晶体同层、跨刀口）

短代码：crCu--Cu:CuCu--Cu:crCu--Cu:crcr--cr:CuCu----:crcr----:P-cr----:Cucr----
稳定 ✔；半破 → 第一象限 = cT.T.cPT ✔，第二象限 = TTTT.ccc
```

要点：

1. **四列都必须连续接地（紧图形）**：`cTccTcPT`、`TTTcTccc`、`TTTc` 都是紧列，没有洞；
2. **第四象限的晶体必须在 L4**（与临时晶体同层），并且**下面必须垫满普通格**
   ——`TTTc` 合法；只放一颗悬空晶体（如 `...c....`）**不合法**：
   晶体下方是空 ⇒ 违反条件四（晶体下洞需要普通资源）；
3. **第三象限仍是空**（与 §4.13 的结论一致）；
4. **配对列 `TTTT.ccc` 是 S**（五项 ✔、D ✘、F ✔），可以单独制作；
5. 前态两列 `cTccTcPT`、`TTTcTccc` **都是 S**——正符合定理 6 的表述
   （「存在两根 S 列，拼合后的一次完整下落恰好得到该半边」）。

### 2.1 造辅助列的硬规则（论文明文，不是本方约定）

> **辅助列一律做紧列：连续接地、满高、不留空隙。**

论文原文（逐条引用）：

| 构造 | 原文 |
|---|---|
| 构造 A | 「把一个从地面连续排列、只含 `T`/`c` 的列称为**紧列**」「每列都**连续接地**，所以组装时不会掉落」 |
| 构造 B | 「普通单格与单顶针可以逐格堆叠，制造任意**连续接地**的 `T`/`P` 列」 |
| 构造 C | 「两根柱都必须覆盖目标的现有高度」 |
| 构造 D | 「在目标另一侧装一根**连续接地**的辅助列。辅助列仅第 k 层为晶体，**其余都是普通格**」 |
| 构造 G | 「制作**满高**辅助列 B：第 k 层为晶体；第 k−1 层为针；**其他层为普通格**」 |
| 构造 H | B / E / N 每层都有材料（晶体 / 针 / 普通格），**没有空层** |

推论：

- **含晶体的辅助列必须满足条件四**（晶体下方有材料）。只放一颗悬空晶体 `...c....` 不合法；
- **需要「下降层」时不要留洞，而是在那一层放一颗晶体**：
  半破时它与临时晶体一起被碎掉，切完洞自然出现；
- 不参与产物的象限（第三象限）留空最省。

**实测对照**（`cT.T.ccc`，8 层）：

| 托柱写法 | 紧列 | 合法 | 半破结果 |
|---|---|---|---|
| `TTTcTTPT`（受降层放晶体） | ✔ | ✔ | `cT.T.ccc` ✔ |
| `TTT.TTPT`（受降层留洞） | ✘ | ✔ | `cT.T.ccc` ✔ |

两种都能成，但**只有紧列版符合论文要求**；留洞版虽然物理上可行，但违反构造 A/D/G 的明文规定。
14 层的两个例子（`cTT.cccT.T.ccc`、`cT.T.T.T...ccc`）把托柱的洞换成晶体后同样成立 ✔。

> 早先「必须留洞」的说法**已撤回**——那是把「切完的状态」误当成了「前态」。

## 3. 论文的算法 8 覆盖不到这一格（重要）

**定理 6**：一个四象限半边 Q 半破可得 ⟺ 存在两根 S 列，使它们不带外柱、
直接拼合后的一次完整下落恰好得到 Q。

**算法 8**（半边判定及前态选择）给了两个候选：

```
第一候选：目标本身
  1. 两列都属于 S
  2. Q 稳定（一次下落后仍等于 Q）
  3. 都通过 ⇒ 用 Q 当前态

第二候选：联合逆提升（第一候选失败时）
  1. 两列各有晶体，且最高晶体不等高
  2. 取较低的那枚，找它的最大粘连组 G，其最低层为 b
  3. 在 b 以下找最高非空层 a
  4. 要求：第 a 层两列都是普通格（水平 TT）；a < b；a+1…b−1 两列都空
  5. 把这对普通格一起从 a 提到 b−1 ⇒ 候选前态 Q′
  6. Q′ 两列都属 S 且一次下落恰好得到 Q ⇒ 接受
```

对这一格逐条检查：

| 候选 | 检查 | 结果 |
|---|---|---|
| 第一候选 | Q1 = `cT.T.cPT` ∈ S ？ | ✘（S 不成立） |
| 第二候选 | 两列最高晶体：Q1 在 L6、Q2 在 L8，不等高 ✔；取 Q1 的 L6，其粘连组含 Q2 的 L6–L8，b = 6；b 以下最高非空层 a = 5；**第 5 层要两列都是普通格** | ✘（Q1 的 L5 是空） |

**两个候选都拒绝，但该半边确实可得**（§2 实测）。
⇒ **算法 8 相对定理 6 不完备**：定理 6 只说「存在两根 S 列」，
而算法 8 的两个候选只是两条构造路径，不覆盖全部。

论文作者自己给出的例子（例 3）恰好是第二候选能命中的形态，
所以这条不完备性在论文里没有暴露出来。

## 4. 设计：新增第三候选（半边工序）

### 4.1 分层结构（推荐）

```
SolveCorner(target, column, n):
    五项 ✘                      → NotProducible
    n ≥ 6                       → 现有算法（S ⟺ 五项，构造 F 等）
    n == 4 且 S ✔               → 现有角工序（单角 + 托柱）
    n == 4 且 S ✘ 但五项 ✔      → 半边工序（两列一起做）
```

### 4.2 半边工序的三个候选

```
候选 1：算法 8 第一候选（Q 自身：两列都 S 且 Q 稳定）
候选 2：算法 8 第二候选（联合逆提升：把一对普通格整体抬高）
候选 3：新增 —— 「临时晶体 + 保险丝 + 一刀」（本例）
        ① Q1 = 目标列，把 (d,s) 之间的普通材料提到 s−1，洞全填临时晶体
        ② Q2 = 提供环：与 Q1 顶部三层咬合（Q1 顶部是 c-P-T 之类，Q2 对应层是 c-c-c）
        ③ Q3 = 空
        ④ Q4 = 保险丝柱：只需在「临时晶体所在层」放一颗晶体（跨刀口）
        ⑤ 一刀半破；回放验证两列逐格等于目标半边
任一候选通过回放 ⇒ 半边可得
```

候选 3 与构造 G（§15）的关系：**同一个「临时晶体 + 保险丝 + 定向碎晶」机制**，
区别只是保险丝碎的是 Q1 的临时晶体、而 Q1 的上部由 Q2 的晶体段提供环支撑。

### 4.3 判定条件（把用户观察写死）

> 「第二象限最上面必须是三个晶体，与第一象限的上面三层构成循环支撑结构」
> 「这个角只会在 n = 4 特殊，n ≥ 6 依旧能被现有算法覆盖」

实测确认：

| 检查 | 结果 |
|---|---|
| n = 4：`cT.T.cPT` → IsComplete | ✘（不可制作，符合 S 判据） |
| n = 6：同一列 → IsComplete | ✔（构造 F） |
| n = 8：同一列 → IsComplete | ✔（构造 F） |

所以半边工序**只需要在 n = 4 启用**；n ≥ 6 保持现有路径。

## 5. 其他设计选项（对比）

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A（推荐）** | 分层：S 角走角工序，非 S 角升级半边工序（3 候选） | 与论文分层一致；复用交换链的半边判定；覆盖全部非 S 角 | 需要实现半边工序与三个候选 |
| B | 只在交换链里处理（半边不可得就当交换失败） | 改动小 | 直接丢掉本来能做的形状 |
| C | 角工序一律升级为「两列一起做」 | 实现统一 | S 角也被迫带上配对列，浪费且改动大 |
| D | 只加候选 3（用户方案），不做 1、2 | 改动最小 | 候选 1、2 能命中的形态反而做不出来 |

---

## 6. 落地清单（给主智能体）

1. `IsSColumn(col, n)`：n ≥ 6 只看五项；n = 4 用 `五项 ∧ (D∨F)`（已完成）；
2. 角工序在「五项 ✔ 且 S ✘」时**不要直接返回不可制作**，改为调用半边工序；
3. 半边工序实现三个候选 + 回放验证；
4. 返回类型扩展：工序单要能表达「两列一起做」（现在的 `AngleWorkOrder` 是单列的）；
5. 与交换链对接：`Swappable` 里「半边可得」的判定可以复用同一套候选。

---

## 7. 结论

- **一、目前 n=4 的算法不足以制作该角**——判定正确（S ✘），但没有半边级路径；
- **二、合并方式**：新增「半边工序」，三个候选（算法 8 的两条 + 用户的「临时晶体 + 保险丝」），
  回放验证后输出两列一起做的方案；
- **你的方案是正确的，而且可以简化**：第四象限只需一颗保险丝晶体，第三象限留空；
- **额外发现**：论文算法 8 的两个候选不完备（本例两个都拒绝，但半边确实可得），
  需要候选 3 补上。
