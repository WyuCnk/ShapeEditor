### 3.1 为什么 R1 一次顶针做不了（结构性说明）

一次 Pin 之后，唯一还能当「固定停靠点」的东西只有两类：

1. 顶针在第 1 层补出来的针；
2. 紧贴第 1 层、且**没有被碎晶打断**的普通格（B 的实心段）。

其它所有能当支撑的东西（E 的满高纯晶体柱、B 的晶体桥、A 的临时晶体段）都会在
「E 顶端超限整根碎」时被同一簇晶体的破碎带走。因此每一个「下降通道」的上方都不再
有任何固定材料 —— 落差 ≥ 2 层的普通格只能一路落到**已经落定的那一枚普通格正上方**。

`P.T.T..c`（8 层）的实测正是如此：

```
A = cccTcTc.   （两枚源普通格在 L4、L6，目标 L3、L5）
I（顶针前）= {2,3,4,5}、J = {4,6}
B = TccccT..   N = TTTTPTPT.
Pin → PTT....c   （两枚普通格停在 L2、L3；目标要 L3、L5）
```

第二枚源格在 L6（顶针后 L7）往下落时，B 在它这一层是**晶体桥**（`I` 里的 `{4,5}` 段），
碎晶后连同 E 一起消失，于是它同样没有陪落的普通格。实测两枚普通格都没有停在自己
该停的层：第一枚（目标 L3）一直落到第 1 层的针上方（L2），第二枚（目标 L5）被第一枚
挡住，叠在 L3 —— 这就是「落地栈」现象：**一枚顶针只提供一个停靠层**（针 / 紧贴针的
普通格），第二枚只能叠在它上面。

R1 要清掉必须引入**第二次顶针 / 第二次落地**（多一个停靠层），或按 §15 逐块多刀，
不是把 A、I、J 再调一调就能解决的。

## 5. 结论

1. **两段开关还没归零（29 例）**，所以「后两段兜底（带下降通道扫描 / 下移一格扫描）」
   这一轮**不删**；本轮只保证 `P.T...c` 这一族清零、失败数从 72 降到 29。
2. 残余两族都不是「A / I / J 再调一调」能解决的：
   - **R2 / R3（13 例）**：构造 H 的顶针只在第 1 层补针（N1）。目标在第 2 层或最高层
     有针时，要么扩展顶针原语（允许第 k 层补针），要么改走「针 + 堆叠」的另一条子配方；
   - **R1（16 例）**：一次顶针只有一个可停靠的落地栈（见 §3.1）。要造出两个落点不相邻的
     普通格，必须**多刀**（§15 逐块，每块一刀）或**多次顶针**（每个落地栈顶一次）。
3. 复核口径：
   - 诊断入口 `AngleWorkOrderBuilder.DescribeConstructedH`（`ShapeEditor.Core/Analysis/ConstructHDiagnostics.cs`）
     与生成走同一条链：`BuildPreStateH` → `BuildDescents` → `BuildAuxColumns` → 真实 `ShapePhysics.Pin`；
   - 三处更正都在 `ShapeEditor.Core/Analysis/AngleWorkOrder.cs`：
     改正 1 在 `BuildDescents`（`I = ∪[d, s−1]`）与 `BuildPreStateH` 第 5 步（保留真实落点 `d`）；
     改正 2 在 `BuildPreStateH`（`BTop` / `NTop`）与 `BuildAuxColumns` / `TryBuildConstructedHPaperCore`（`bTop` / `nTop`）；
     改正 3 在第 4 步的「抬到填充段顶端」与第 4 步末的显式补段 pass，配套在第 2 步的 `shiftFrom`。
4. 默认模式（开关关闭）数字不变（3–9 层全过）：
   `AUDIT success=2125 failures=0 falsePositives=0`、`LAYERAUDIT 7 = 4320/0`、
   `LAYERAUDIT 8 = 12646/0`、`NINEAUDIT 36508/0`、`TIGHT onlyAux=0`、
   `HOLES targetHoleNoSub=0`、`FILLBREAK n=0`、`COLLAPSE steps=0`、`Q1AUDIT missing=0`、
   `P1AUDIT / P1ALL violations=0`、`HALFAUDIT halfComplete=6`。
5. 测试：
   - 新增回归项 `角工序:两段开关覆盖深间隙族`（13 例逐条断言：完成 + 初始前态 P1 +
     末步逐格等于目标，跑完恢复开关）；
   - 更新断言 `角工序:辅助列的洞换晶体`：`P.T..c` 的第 2 象限由 `TccTTT` 改为 `TccT..`
     （改正 2 让 B 不再满高，P4 是陪落的普通格、P5 起留空）。
