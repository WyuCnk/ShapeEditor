# §0 实现总览（照这一节写代码）

## 0.1 三条普适原则

| 原则 | 内容 |
|---|---|
| **P1** | **初始前态**里每颗原生晶体都必须直接坐在普通格上（不能坐空、不能坐临时晶体）。间隙由「那枚普通格落回去」产生。**只约束初始前态**，多刀的中间态允许晶下间隙。 |
| **P2** | 顶针把整列上移一格 ⇒「顶针前」=「顶针后下移一格」，再按 P1 抬升。 |
| **P3** | 辅助列一律紧列（无洞）；碎晶 2 根、顶针 3 根；第三象限留空；**B/N 只做到最高有效层，上面留空**（不是满高）。 |

## 0.2 总流程

```
SolveCorner(shape, column, cap):
  ① 剥尾        Hc = 整图最高晶体层；Hc 以上（含针）存为尾部
  ② 判定        五项 → 分类 → S 判据；不合法/不满足 S ⇒ NotProducible
  ③ 分档        C / A+C / F(n≥6) / 算法5(底格是针) / 算法6(D) / 算法4(其余)
  ④ 施工        n≥6：算法 1 → 2 → 接尾 → 构造 F 送回
                 n=4：算法 5 或算法 6（各见 §0.4/§0.5），顶针一次
  ⑤ 接尾        n=4 顶针路线：顶针之后逐层 Stack（每层先把托柱加高）
                 n≥6 构造 F 路线：接尾在【送回落位之前】
  ⑥ 验收        §0.6
```

> ⚠️ **接尾时机两条路线不同**（论文算法 3 第 3 步在送回之前；n=4 顶针路线实测在顶针之后）。

## 0.3 几个必须的取值

| 量 | 怎么算 |
|---|---|
| `Hc` | 整图所有列里最高的晶体层 |
| `f0` | 目标列里最低的晶体层 |
| 顶针次数 | 见 §0.5 |
| `I` | `∪[d, s−1]`（**完整通道**，可跨多层）∪ {每个临时晶体段在顶针后的最上层} |
| `J` | 所有源层 `s`（层号用**顶针后**） |
| `BTop` | `max(max(I), 最高源层 − 1)`；B 到 `BTop` 为止，以上留空 |
| `NTop` | `max(max(J), 最高原生晶体目标层 − 1)`；N 到 `NTop` 为止，以上留空 |
| E | 满高纯晶体柱（cap 那么高） |

## 0.4 算法 6（底格非针、D 成立）：**论文四步**

> 依据 `docs/列与可分形状的判定和构造.md` §479–521（算法 6 与例 2）。
> v3 之前的「七步 ≈ 下移边界外扩」是近似，**废弃**。

### 第一步：底块提升（至多两次）

```
只要「最底两层」还没有都空：
   ① 找出最下方非空位置开始的【最大连续普通块】
   ② 把整块沿其上方紧邻的空段尽量上移，直到紧贴下一份材料
   ③ 记录：块的原区间、上移距离、每格标签
⇒ 记录序列 B1、B2（至多两个）
```

### 第二步：正规化 + 确定底格恢复方式

```
① 对整理后的核心运行【算法 1】：每个「晶体下洞」把最近的普通格提高一格
   ⇒ 正规列 v + 恢复表 M = { s → d }
② 最后一次提升的底块，在 v 中保持整理完成时的位置
③ 决定底格怎么回去：
     · 没有底块提升        → 用 M
     · 最后一块原从第 1 层起 → 先执行 M，之后让整个底块弱落回去
     · 最后一块原从第 2 层起 → 设它现在最低格在 b 层，加一条 b→2，记作【额外动作 e】
   （只会有这两类起点，所以最多加一条非弱下降）
```

### 第三步：找出需要**提前弱落**的记录

```
若没有 e → 跳过
若有 e   → 查 M 中每条 s→d：
             若 v 中「第 s 层以下最近的一枚普通格」正是第 b 层那枚
             ⇒ 这条记录【提前】
（至多一条，落点为 b+1：先执行它，由第 b 层普通格托住，
  再安排第 b 层那枚普通格的下降）
```

### 第四步：正向制作

```
① 制作 v【整体低一层】的带柱形状（仍是正规列，算法 2 可做）；
   顶部留出一层空位，供最后一次顶针把目标送回所需高度
② 执行第三步选中的【提前弱落】（源层、目标层号都减一）
③ 构造 H 的下降表 = M 去掉提前的那条 + 额外动作 e（如有）
   此时临时晶体已删 ⇒ I 只含下降通道，**不再加临时段顶格**
   J = 所有源层 s；I = ∪[d, s−1]
④ 辅助列：B 的 z+1∈I 放晶体（到 BTop）；N 的 z+1∈J 放针（到 NTop）；E 满高；
   第三象限空
⑤ 顶针一次 → 碎临时晶体、完成全部恢复下降
⑥ 【按底块提升的逆序恢复各块】；块内从最低格到最高格依次弱落；
   已经由 e 放回第 2 层的最低格跳过
```

### 例（论文例 2，`TT.T.c`）

```
底块提升：TT.T.c → .TTT.c → ..TTTc
第二步：最后一块原从第 2 层起，现最低格在 b = 3 ⇒ 加 e: 3→2
第四步：低一层制作 .TTTc → 顶针 + 3→2 ⇒ .T.TTc
        → 弱落 4→3、5→4 ⇒ .TTT.c
        → 弱落 2→1、3→2 ⇒ TT.T.c
```

## 0.5 算法 5（底格是针）：**一次批量恢复**

> 依据 §467–477。

```
1. 对核心执行【算法 1】，每个晶体下洞提高最近的一枚普通格 ⇒ v + 恢复表 s_i→d_i
2. 把 v 的空填成临时晶体，【去掉一枚底针，整体层号减一】，
   用紧列和其余底针制造所得列（⇒ 前态里已经有 m−1 枚针）
3. 构造 H：J = 所有 s_i；I = 各段 [d_i, s_i−1] + 每段临时晶体的顶格
4. 【顶针一次】：补回所欠的那枚底针，同时碎临时晶体、完成全部恢复下降
5. 清理辅助件，恢复普通柱
```

**顶针次数 = 1**（前态里已放好 m−1 枚，一次顶针补回第 m 枚）。
论文附注：底部已有针 ⇒ 所有普通格的目的层都 ≥ 2，提升区间彼此分离，落脚支撑不会同时被移走。

> 早期用「m 次顶针、前态不放针」也能得到同样的结果（`PP.T.cTc` 实测 2 次顶针 ✔），
> 但那是**等价变体**，不是论文写法。实现一律按本节（前态放 m−1 枚针 + 顶针 1 次）。

**终止条件是结构性的**：底针全部就位 ⇒ 停；不是按次数枚举。

## 0.6 验收

```
1) 初始前态：每颗晶体下方非空（P1）；辅助列紧列无洞
2) 四列过五项 + 整体稳定
3) 顶针/半破后 col0 逐格 == 目标（中间态允许晶下间隙）
4) 尾部逐层堆完后 col0 逐格 == 目标
5) 失败返回 Uncovered 并记录中间值 —— 不允许退回枚举
```

## 1. 三条普适原则

### P1（最重要）晶下间隙只能靠「抬升普通格」产生

> **pre-state 里，每颗原生晶体都必须直接坐在普通格上**——不能坐在空上、也不能坐在临时晶体上。
> 间隙是在施工过程中由「那枚普通格落回去」产生的，而不是靠「炸掉晶体下方的东西」产生的。
>
> ⚠️ **口径（2026-11-16 确认）：这里的 pre-state 指「初始前态」**；多刀之间的中间态允许晶下间隙。
> 以 §0.1 为准。

理由（用户的原话）：*制造间隙用的晶体，不能破坏原生晶体*。
若晶体下方是空，要造洞就得在它正下方放临时晶体；晶体纵向融合，
一碎就连带把原生晶体炸掉（实测：`T.T.c` 的两刀模拟得到 `T.T..`，原生晶体没了）。

**推论**：

```
目标 T..c（晶体上方有洞、下方是空）  ⇒  pre-state 必须是 .Tc（晶体下移一格，坐在 T 上）
目标 T...c（下方 2 个空）           ⇒  pre-state 必须是 ...Tc（普通格抬到晶体正下方）
```

### P2 整体下移一格 = 顶针的逆

顶针把整列**上移一格**，所以「顶针前的图形」= 「顶针后的图形**下移一格**」，
再按 P1 把该抬的普通格抬到晶体正下方。顶针之后的自然坍落会把多余的一层补回来。

### P3 辅助列一律紧列；碎晶 2 根、顶针 3 根

| 路线 | 辅助列 | 角色 |
|---|---|---|
| 碎晶（构造 D / G） | **2 根**：托柱 + 桥柱 | 托柱支撑、桥柱把临时晶体接到刀口另一侧 |
| 顶针（构造 H） | **3 根**：托柱 + 落块柱 + 引爆柱（纯晶体） | 引爆柱顶端超限整根碎，落块柱带目标格回落 |
| 不参与产物的象限 | **留空** | 第三象限实测冗余（§4.13） |

```
    ⑨ 验收        → 七条                              §8.3
```

## 3. 步骤 ①：剥尾（形状级）

```
Hg = max{ 该列最高晶体所在层 | 所有列 }
tail = 所有列在 Hg+1 … 层顶 的格子（逐层保存）
core = 图形截断到 Hg 层
```

- `Hg` 是**整图**最高晶体层 ⇒ `Hg` 以上必然没有晶体 ⇒ 尾部天然是「无晶体尾部」，
  **不需要额外的判据**。
- 例：`Q1 = T.c.T`、`Q2 = TTTTT` ⇒ Hg = 3 ⇒ core 的 Q1 = `T.c..`、Q2 = `TTT..`。
- 例：`Q1 = T.c.T`、`Q2 = TTTTc` ⇒ Hg = 5 ⇒ 不剥。
- ⚠️ 注意：剥尾是**形状级**的；某列自己的尾部（高于**该列**最高晶体、但低于 Hg）**不剥**，
  它仍要由角工序处理（见 Q5）。

## 4. 步骤 ②：判定

```
1) 五项条件（论文定理 1）→ 失败 ⇒ NotProducible      // 唯一的否定判据
2) 分类：最高晶体以下无空 ⇒ Simple；有晶体但无空 ⇒ 无晶体；否则 NeedsCrystalBreak
3) S 判据：n = 4 → 五项 ∧ (D ∨ F)（定理 3）
           n ≥ 6 → 五项            （定理 2）
   不满足 ⇒ NotProducible（该列不可造为「带托柱列」）
```

## 5. 步骤 ③：分档（按论文，先选再动手）

```
无晶体                            → 构造 C（逐层追加 T/P）
Simple                            → 构造 A（紧列）+ 构造 C（尾部）
NeedsCrystalBreak:
    n ≥ 6                         → 算法 1 → 2 → 3（构造 F 送回）
    n = 4:
        底格是针                   → 算法 5（一次批量恢复）
        D 成立                     → 算法 6（底块提升 → 正规核心 → 构造 H → 恢复）
        其余（D ✘、F ✔）          → 算法 4（递归提升 + 环下落）
```

**顺序约定**：「底格是针」优先于「D 成立」。

## 6. 步骤 ④：核心计划（算法 1/2 的通用部分）

### 6.1 提升（算法 1）

```
for 晶体段 seg，从下往上:
    if seg 底端正下方非空: continue
    沿连续空位向下找到最近的普通格 x
    把 x 抬到「seg 底端正下方」
    记录 (新层 s', 原层 s)
    若段长 1–2 且 x 的原位置下方仍为空 → 递归继续抬下一个普通格
```

**结果**：每颗晶体都坐在材料上（满足 P1）✔。

### 6.2 正规核心（算法 2 第 1 步）

```
把「最高晶体以下」的所有空位临时填成晶体 → 得到紧列（构造 A 可造）
```

### 6.3 临时晶体块

```
按纵向连通性，把「临时填进去的晶体」分成块
每块记录 [bottom, top]；锚层 = top   （桥柱在该层放晶体）
```

### 6.4 底块提升（仅算法 6，且仅当最底两层非空时）

> ⚠️ **v3 起，「底块提升」已并入 §0.4 第 ② 步的「下移边界外扩」**，
> 不再作为独立步骤。本节保留论文原步骤的记录，实现时不要再单独写一遍。

```
while 最底两层 不都空:
    找「最下方非空位置起的最长连续普通块」
    沿它上方的空段上移到「紧贴下一份材料」
    记录块的 (原区间, 新区间)
（论文：至多两次）
```

## 7. 步骤 ⑤–⑦：两条施工路线

### 7.1 碎晶路线（构造 D / G）——通用形态

```
前态：
   第 1 象限 A = 正规核心（紧列）
   第 2 象限 S = 托柱：满高普通格；
                在「被提升格的落点层 … 原层−1」逐层放针（构造 E 的弱落）
   第 3 象限    = 空
   第 4 象限 B = 桥柱：满高普通格；在每个临时晶体块的锚层放一颗晶体

施工：
   ① 一刀（若所有锚层可被同一刀口覆盖）
      否则逐块一刀，自上而下
   ② 每刀之后按真实 Collapse 落定，记下结果
   ③ 删完所有临时晶体块后，被提升的普通格自上而下落回原位
   ④ 构造 C：托柱换成满高普通柱、拆桥柱、清辅助列 → 目标角（S 形态）
```

**要点**

| 项 | 规则 |
|---|---|
| 一刀还是多刀 | 落点区间互不重叠 ⇒ 一刀；否则逐块、自上而下（§4.12） |
| 刀口 | 穿过桥柱晶体与临时晶体块的连接 |
| 保留侧 | 必须含「目标列 + 托柱」（论文构造 D 原文） |
| 恢复顺序 | **从上到下**，且按连通块整段删（§5 规则三） |

### 7.2 顶针路线（构造 H）——通用形态

```
前态：
   第 1 象限 A = 目标列，按 §0.4 的七步生成
   第 2 象限 B = 晶体桥柱：z+1 ∈ I → 晶体，否则普通格；**做到 BTop 为止，以上留空**
   第 3 象限 E = 满高纯晶体柱（引爆柱）
   第 4 象限 N = 针槽柱：z+1 ∈ J → 针，否则普通格；**做到 NTop 为止，以上留空**

   其中（层号一律用**顶针后**的编号）：
       I    = ∪[d, s−1]  ∪  {每个临时晶体块的最上层}
       J    = { 每个需要下降的源层 s }
       BTop = max(max(I), 最高源层 − 1)
       NTop = max(max(J), 最高原生晶体目标层 − 1)

施工：
   ① 装 A | B | E | N
   ② 顶针一次：整组上移一格，E 顶端超限整根碎掉，
      B/N 按 I/J 放好的晶体与针决定「哪些格沿通道下降」
   ③ 自然坍落把剩余落差补完
   ④ 构造 C：换托柱、拆 B/E/N → 目标角
```

> ⚠️ **B/N 不满高是硬性要求**：满高会失败（`P.T...c.` 满高 → `P....Tc` ✘；

### 13.6 A 的生成规则（**最终版**，8 个样例验证）

验证过的样例：`.T.c`、`.T..T..c`、`T..T...c`、`T...cT.T.c`、`T..cT.T.c`、
`P.T..c`、`..T.cc`、`..T.cTc`。

```
输入：目标列 t（1-based）、cap
输出：A、I、J → 进而 B / E / N


【第 1 步】定基准层 f0
    f0 = 目标列里最低的晶体所在层
    没有晶体 ⇒ 不走本流程（构造 C / A）


【第 2 步】逐格放置（N2）
    对每个目标格（层 f、类型 t[f]）：
        f <  f0  ⇒  A[f] = t[f]          （最低晶体以下：不动）
        f >= f0  ⇒  A[f-1] = t[f]        （最低晶体及以上：下移一格）
    若 f >= f0 且 f-1 < 1 ⇒ 失败，换碎晶路线


【第 3 步】第 1 层的针（N1）
    if 目标 L1 是 P:
        A[0] 必须非空 —— 这枚针由「顶针操作」在 L1 补出来，A 里不要放 P
        A[0] 放普通格或临时晶体（按第 4 步的填充规则决定）
    else:
        A[0] 必须为空 —— 否则顶针会凭空多补一枚针
        若第 2 步把某个格放到了 L1 ⇒ 把它抬到 L2（并在 L1 留空）


【第 4 步】临时晶体填充
    A 里出现「下方有格、上方有格」的连续空层 ⇒ 填临时晶体
    被填充段上方的那个格（普通格或晶体）⇒ 抬到填充段的顶端
        （例：P.T..c 的 T@3 被抬到 A@4，顶针后 5 → 坍落到 3）
    P1 自检：**初始前态**里每颗晶体下方必须非空
        不满足 ⇒ 把下方最近的普通格抬到它正下方；抬不动 ⇒ 换碎晶路线
    ⚠️ P1 只管初始前态；多刀的中间态允许晶下间隙（N3）


【第 5 步】降表（层号一律用「顶针后」= A 的层号 + 1）
    逐格比对 A 与 t：
        晶体：A@f-1 → 顶针后 f            ⇒ 不下降
        普通格 A@f   （f < f0）  → 顶针后 f+1 ⇒ 声明下降 1 层 → f
        普通格 A@f-1 （f >= f0） → 顶针后 f   ⇒ 不下降
    J = { 需要下降的格在顶针后的层号 s }
    d = 该格的目标层
    **I = ∪[d, s−1]（完整通道，可以跨多层）** ∪ { 每个临时晶体段（顶针后）的最上层 }

    ⚠️ 2026-11-16 更正：这里原本写成「只声明 1 层（d = s−1）」是**错的**。
    深间隙必须用完整通道，实测（P.T...c，7 层）：

        I = {4}        （单层）      → P...T.c  ✘
        I = {3,4}      （下扩一格）  → P..T..c  ✘
        I = {3,4,5}    （完整通道）  → P.T...c  ✔


【第 6 步】辅助列
    B[z] = (z+1 ∈ I) ? 晶体 : 普通格
    E[z] = 晶体                    （满高纯晶体柱，负责碎掉临时晶体）
    N[z] = (z+1 ∈ J) ? 针   : 普通格
    第三象限 = 空


【第 7 步】顶针一次 → 坍落 → 验收
    1) 顶针后 col0 逐格 == t
    2) A | B | E | N 四列过五项 + 整体稳定
    3) 初始前态的每颗晶体下方非空（P1）
    4) 临时晶体块全部被碎掉；没有残留
    失败 ⇒ 回第 4 步调整填充段与抬升量；仍失败 ⇒ Uncovered（不枚举）
```

## 15. 多刀半破（同一列需要多次碎晶）

### 15.1 例子：`TT.T.c`

```
目标 TT.T.c = T T . T . c      （晶体在 L6）

第 1 刀
  前态  CuCu--Cu:crCu--Cu:CuCu--Cu:crCu--cr:CuP-----:crCu----
        col0 = TcTcTc   col1 = TTTTPT   col3 = TTTc
  半破 → col0 = TcTT.c
                 ↑ 还有 c@2、c@6 两段临时晶体没清

轮间：交换「支撑柱 ↔ 爆破柱」（构造 C）
  第 2 刀
  前态  CuCu--Cu:crCu--cr:CuP-----:CuCu----:--Cu----:crCu----
        col0 = TcTTTc? → 半破 → TT.T.c ✔
```

同样需要多刀的：`TT.T.T.c`、`cTT.T.c`。

### 15.2 终止条件必须是结构性的

> **每一刀恰好消掉一个「临时晶体连通块」；所有块消完（集合为空）时终止。**

```
要碎了集合 K = { 临时晶体连通块 }        ← 由 §13.6 ③ 生成的块，按纵向连通分组
while K ≠ ∅:
    ① 取 K 中「最上面的块」b        （论文：从上到下）
    ② 若 b 在刀口的另一侧 ⇒ 交换支撑柱与爆破柱（构造 C 的支柱交接）
    ③ 生成这一刀的前态：
         - b 所在层由桥柱/保险丝柱的晶体接到刀口另一侧
         - b 之外的临时块**保持原样**（它们下一刀再处理）
         - 目标列当前形态的晶体必须坐在材料上（P1）
    ④ 半破 → 落定 → 得到新的目标列
    ⑤ K = K \ { b }
```

**为什么必然终止**：每轮 `|K|` 严格减 1，且 `K` 有限。**不按轮数判断，也不枚举刀数。**

### 15.3 轮间的「交换辅助柱」

第 ② 步的依据是论文构造 C 的支柱交接：

```
先装新柱（另一侧） → 由新柱接管支撑 → 拆掉旧柱
```

`TT.T.c` 实测：第 1 刀的爆破柱在第 4 象限（`TTTc`），第 2 刀换到第 2 象限（`cr...`）——
因为第 2 个要碎的块在另一侧。

### 15.4 与「一刀多段」的关系

- 若多个块的**落点区间互不重叠**，且都能被同一条刀口覆盖 ⇒ **合成一刀**（§4.12）；
- 否则按 §15.2 逐块分刀，**自上而下**；
- 两种情况都不改变终止条件（`K` 清空）。

### 15.5 验收

```
1) 每一刀后：目标列逐格 == 该轮的期望中间列
2) 最后一刀后：目标列逐格 == 目标
3) 每一轮的前态：每颗晶体坐在材料上（P1）
4) 每轮前后：辅助列紧列、无洞
5) K 的块数就是刀数（不允许出现"同一块被切两次"）
```

所以：

```
初始前态（工序的第一张图）  ⇒ 必须满足 P1（晶体坐在普通格上）
中间态（多刀之间的形态）    ⇒ 允许晶下间隙，不加 P1 检查
```

验收时 P1 检查**只跑第一张前态**，主智能体现有的严格 P1 闸门要放宽到这一步。

**N2 的第三个验证：`..T.cc`**

```
前态 --CucrCu:--crcrCu:CuCucrP-:cr--crCu:cr--crCu:----cr--

col0 = ..Tcc.     （T@3, c@4, c@5）
顶针 → ..T.cc     （T@3, c@5, c@6）  ✔ 实测

对账：最低晶体在 L5 ⇒ L5 以下的 T@3 不动；L5、L6 两颗晶体下移一格 → A 的 4、5 ✔
P1：c@4 坐 T@3 ✔、c@5 坐 c@4 ✔
```

`..T.cTc`（A = `..TcTc.`）与 `..T.cc`（A = `..Tcc.`）**用的是同一条规则** ✔。

## 17. 最后 29 例：R1–R3 的三条规则

> 三个前态均已逐格实测通过。

### 17.1 R1（16 例）：一次顶针可以做多个下降，只要 A 有多个源普通格

报告里判断「一次顶针只能有一个落地栈」是**错的**。实测 `P.T.T..c`（8 层）：

```
A = ccTccTc.     B = TcTTcT..     E = cccccccc     N = TTPTTPT.
顶针一次 → P.T.T..c  ✔
```

A 里有**两枚源普通格**（T@3、T@6），中间用临时晶体夹开：

```
A = c c T c c T c .   （T@3、T@6，临时晶体在 1,2,4,5,7 段里）
    ↑ ↑   ↑ ↑
```

- 第一枚 T@3 → 顶针后 L4 → 落到目标 L3 ✔
- 第二枚 T@6 → 顶针后 L7 → 穿过被碎掉的 c@6 落到目标 L5 ✔（它的“刹车”是下面已经落定的 T@3）

**所以 R1 的规则不是“分两次顶针”，而是：**

```
每个要下降的普通格，在 A 里都放成【独立的一枚 T】，
两枚之间用临时晶体隔开（临时晶体在 I 里，会被碎掉）
```

### 17.2 R2（11 例）：目标底部的**连续针段长度 = 顶针次数**

实测 `PP.T.cTc`（8 层）：

```
A = ccTcTc..     B = TcT.....     E = cccccccc     N = TTPTTT..
顶针两次 → PP.T.cTc  ✔
```

**规则（与论文算法 5「底针批量恢复」同一思路）**：

```
① 数目标列底部的连续针段长度 m（P 从 L1 开始连续）
② 把这段针剥掉，得到「去掉底针后的角」
③ 用 §13.6 七步分析剩下的角：
     若分析结果需要「一次顶针来顶破晶体塔造间隙」⇒ 这一次顶针同时补出第 1 枚针
     若不需要 ⇒ 这枚针也要单独顶出来
④ 剩下的 (m − 已补出的枚数) 次顶针，逐次在 L1 补一枚针（整列同时上移一格）
⑤ 顶针次数用尽时，列应逐格等于目标
```

- 每次 Pin 都在 L1 补一枚针（因为前一次的针让 `A[0]` 非空）；
- 所以 m 枚底针 = m 次顶针，**结构性终止条件 = 底针全部就位**。

### 17.3 R3（2 例）：顶部的针走「剥尾 + 最后堆叠」，不用顶针

实测 `P.T.T..cP`（9 层）：

```
A = ccTccTc..    （与 P.T.T..c 相同，只是多一层空）
顶针一次 → P.T.T..c  ✔
再堆一个针到 L9 → P.T.T..cP  ✔
```

**规则**：目标列**高于最高晶体**的部分（不管是 T 还是 P）都走 §5.3 的剥尾 + Stack，
**不参与顶针**。顶针只负责核心（最高晶体及以下）。

⚠️ 例外：`cT.T.cPT` 这类需要半边工序的角，整体走半边路线（§19）。

### 17.4 合并后的完整流程

```
① 剥尾：Hc = 整图最高晶体层；Hc 以上存为尾部（含针）
② 取核心列，数底部连续针段 m
③ 剥底针：核心列去掉底部 m 枚针 → 得到「主体角」
④ 用 §13.6 七步分析主体角：
     放置（f0 规则）→ L1 处理 → 临时晶体填充 → 降表(I 用完整通道) → B/E/N → 顶针
     其中「顶针次数」= 1（造间隙用）+ (m − 1)（补底针用）
     若主体角只需要补针、不需要造间隙，则次数 = m
⑤ 按次数依次顶针
⑥ 接尾：把尾部逐层堆回去（先加高托柱）
⑦ 验收
```
