### Q-11 中间高度的针——**不存在（被五项条件排除）**

论文五项第二条：**「晶体以下的针只能在底部连续针段中」**。

推论：

```
若目标在 Lk 有针 P（k ≥ 2），且 L1…L(k−1) 不全是针，
而该列在 Lk 之上还有晶体（Lk 不算"最高晶体以上"），
则 Lk 这枚针不在底部连续针段里 ⇒ 违反五项第二条 ⇒ 不是合法列。
```

所以要覆盖的针只有三种位置：

| 位置 | 覆盖规则 |
|---|---|
| `L1` 起的连续针段 | §0.5（顶针 m 次） |
| 最高晶体以上 | §17.3（剥尾 + Stack） |
| 目标 L1 单独一枚针 | §0.5 的 m = 1 情形 |

**没有第四种。** 如果你在 S 列语料里真的碰到中间针，那是 S 判据的 bug，请把列发我。

### Q-12 半边工序 225/229 失败——**是「候选不足」，不是「不可制作」**

数据：7–9 层非 S 合法角 229 个，`halfComplete = 6`，其余 225 个未覆盖。

**判断**：`half-side-work-order.md` 里已经承认「论文算法 8 的两个候选不完备」，
我们补的第三个候选（临时晶体 + 保险丝）只覆盖了少数形态。所以 225 个是**候选不够**。

**缺的那一类（初步分析）**：

```
现有三个候选都是「一刀搞定整列」：
   候选 1：目标列自身就是半边可做的形态
   候选 2：联合逆提升（要求 a 层两列都是普通格）
   候选 3：临时晶体 + 保险丝 + 一刀

而 7–9 层的非 S 角多数有【多个晶体段】，
一刀只能处理一段 ⇒ 需要「分段半边」：
   按晶体段把目标列切成若干段，每段单独做半边工序，段间用构造 C 接起来。
```

**下一步建议**（需要你确认要不要我投入）：

1. 从 225 例里抽 10 个最小/最典型的，按「晶体段数」分组；
2. 对每组试「分段半边」，看是否两段就能覆盖；
3. 若能，写进 `half-side-work-order.md` 的 §4（新增「分段」一节）。
