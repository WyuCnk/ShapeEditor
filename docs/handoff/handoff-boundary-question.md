## 3. 为什么不是「O 的边界」

```
O 是 ①→②→③→④ 的顺序回落：
  ① 失败 → ②；② 失败 → ③；③ 失败 → ④
所以「O 不可行」= 四档全失败 = 空集（3–9 层零失败）
```

**「O 的边界」这个提法没有意义**——它覆盖全部。
有意义的是「每一档的边界」，而其中只有 ①（和 ④）写清楚了。
