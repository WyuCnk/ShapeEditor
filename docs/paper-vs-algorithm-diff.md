## 二、缺漏（按严重度）

### 缺漏 1（最严重）：算法 6 有**四步**，本算法只做了第 1、2 步的一部分

论文 §479–521：

```
第一步  最多两次底块提升：找「最下方非空位置起的最大连续普通块」→ 沿上方空段
        尽量上移直到紧贴下一份材料 → 【记录块的原区间、上移距离、每格标签】
第二步  正规化（算法 1）→ 恢复表 M；
        最后一次提升的底块保持整理完成时的位置；
        若最后一个块原来从第 2 层开始（现最低格在第 b 层）⇒ 增加一条 b→2，记作 e
第三步  【找出需要提前弱落的记录】：若存在 e，则查 M 中每条 s→d，
        若正规列里第 s 层以下最近的普通格正是第 b 层那枚 ⇒ 这条记录提前执行
第四步  ① 制作 v【整体低一层】的带柱形状（仍是正规列，算法 2 可做）
        ② 执行第三步的提前弱落（源/目标层号都减一）
        ③ 构造 H：M 去掉提前记录、加入 e；此时临时晶体已删，I 只含下降通道
        ④ 顶针一次
        ⑤ 【按底块提升的逆序恢复各块】，块内从最低格到最高格依次弱落
```

**本算法（§0.4 七步）缺**：

| 缺的东西 | 影响 |
|---|---|
| **底块提升**是显式步骤，且要**记录块的原区间 / 上移距离 / 标签** | 只做「下移边界外扩」无法支撑第 5 步的逆序恢复 |
| **额外动作 e**（`b→2`） | 底块从第 2 层开始的情形会漏掉一次下降 |
| **提前弱落**（第三步） | 依赖活动支撑的普通格没有先落，构造 H 的下降表会错 |
| **整体低一层制作** | 「顶部留一层空位供最后一次顶针」没有实现 |
| **逆序恢复各块**（块内从低到高） | 最后的回落次序错误 |

**结论**：算法 6 需要按论文的**四步**重写，不能再用「七步 + 下移边界外扩」近似。

### 缺漏 2：算法 5（底针）的框架与本算法不同

论文 §467–477：

```
1. 对核心执行算法 1，得到 v 和恢复表 s_i→d_i
2. 把 v 的空填成临时晶体，【去掉一枚底针，整体层号减一】，用紧列和其余底针制造
3. 构造 H：J = 所有 s_i；I = 各段 [d_i, s_i−1] + 每段临时晶体顶格
4. 【顶针一次】，补回所欠底针，同时碎临时晶体、完成全部恢复下降
5. 清理，恢复普通柱
```

- 本算法 §0.5 的「顶针次数 = 1 + (m−1) = m」结果上与论文一致（m 枚底针 ⇒ m 次顶针）；
- 但论文的**前置**是「先跑算法 1 得恢复表」，本算法 §0.4 没有要求顶针路线先算恢复表，
  而是用「整体下移一格」代替 ⇒ **下降表可能算错**，这正是 R1 那类问题的根。

### 缺漏 3：`TT.T.c` 论文给的是「一次顶针 + 弱落」，本算法给的是「两刀」

论文例 2（§523–538）：

```
目标 TT.T.c
  → 低一层制作 .TTTc
  → 构造 H 顶针 + 完成 3→2  ⇒ .T.TTc
  → 弱落 4→3、5→4            ⇒ .TTT.c
  → 弱落 2→1、3→2            ⇒ TT.T.c
```

本算法 §15 用「两刀半破」做同一格（也能成）。两者都对，但：
- 论文的路线**不需要多刀**；
- 若按论文实现，§15 的多刀只用于「顶针确实做不了」的形态，**范围会大幅缩小**。

### 缺漏 4：算法 3（n≥6）的接尾位置

论文 §357–376 的顺序是：
```
1. 无晶体 → 构造 C
2. 算法 1、2 → 正规核心
3. 【接回最高晶体以上的无晶体尾部】（构造 C 逐层追加）
4. 按提升记录逆序，用构造 F 送回
```

注意 **第 3 步在送回之前**，本算法 §0.2 是「最后接尾」。
对 n=4 的顶针路线，尾部在顶针**之后**堆（实测 `P.T.T..cP` 是「顶针后堆针」✔）；
对 n≥6 的构造 F 路线，论文是在**送回落位之前**接尾。
⇒ **两条路线的接尾时机不同**，§0.2 的「统一最后接尾」是错的。

## 三、修正建议（按优先级）

| 优先级 | 事项 |
|---|---|
| **P0** | 按论文四步重写**算法 6**：底块提升（记录块）→ 正规化 + e → 提前弱落 → 低一层制作 + 顶针 + 逆序恢复 |
| **P0** | **算法 5**：顶针路线先跑算法 1 得恢复表，按 `s_i→d_i` 填 I/J，不再用「整体下移一格」替代 |
| **P1** | 接尾时机分开：n=4 顶针路线＝顶针后接尾；n≥6 构造 F 路线＝送回落位**前**接尾 |
| **P1** | 多刀（§15）范围缩小为「顶针做不了」的兜底 |
| **P2** | B/N 高度与论文 `z=1…H` 的偏差，加注说明按实测执行 |

## 四、一句话结论

**构造 H 的公式全对；错在把「算法 6 的四步」压成了「七步近似」——
底块提升记录、额外动作 e、提前弱落、逆序恢复这四样丢了，这是残余失败的结构性原因。**
