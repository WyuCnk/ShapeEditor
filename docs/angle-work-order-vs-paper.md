## 1. 步骤粒度：已经改好了

早前 `Cut` 后面还跟一个 `Collapse` 步（"下落前 / 下落后"分两步）。
检查当前代码：**`AngleWorkStepKind.Collapse` 已经不再被发射**（`AngleWorkOrder.cs` 与
`AngleWorkOrderHalfSide.cs` 里 0 处），Cut 步的标题直接写成「切割（碎晶并落定）」，
`Shape` 就是落定后的结果。**与论文的「半破」一步语义一致。**

当前各构造的步骤序列（实测）：

| 构造 | 序列 |
|---|---|
| A / C（简单角） | `Note → Support → Stack… → Target` |
| A（无尾部） | `Note` |
| C（塔式） | `PreState → Pin → Support → Target` |
| D（单刀） | `PreState → Cut → Support → Target` |
| D（两刀） | `PreState → Cut → PreState → Cut → Support → Target` |
| G（环下落） | `PreState → Cut → Support → Target` |
| F（n ≥ 6） | `PreState → Cut → Support → Target`（Cut 标题含"落定"与落点说明） |
| Half（非 S 角） | `PreState → Cut → Target` |

## 2. 与论文的差异清单

### A 级（实质性偏离）

**A1. `FillBreak`（填充+暴破）不是论文构造，仍在用**

```
构造分布（≤6 层 S 列）：A 1087 / C 646 / D 291 / FillBreak 77 / H 18 / G 6
```

论文里"碎晶"只有 **构造 D（定向碎掉一个晶体段）**：辅助列连续接地、仅第 k 层为晶体，
刀口穿过它。`FillBreak` 是"把塔下缺口**全部填满**再炸"的实现特例——
形态上更像"构造 A + 一刀"，但**辅助列不满足构造 D 的形态要求**，
而且我们实测过它会留下带洞的辅助列（§17.7 的 7 例全是它）。

→ 建议：把这 77 例逐步替换为 D 或 G。

**A2. 辅助列留洞（7 例）**

`T.ccc`、`T.ccc.`、`T.cccT`、`T.cccP`、`P.T..c`、`TT.ccc`、`T.cccc` 的前态托柱写成
`.TTPT`（L1 留洞）。论文构造 A/B/D/G 一律要求辅助列**连续接地**，需要洞时应在该层放晶体。

→ 修法已验证：`T.ccc` 的托柱 `.TTPT` → `cTTPT`，半破后 `col0 = T.ccc` ✔。

**A3. `P.T..c` 未覆盖（1 例）**

底针 + D 成立的角，算法 5 的分支没打通（`P..T.c` 这类能过，`P.T..c` 不能）。
这是唯一残留的 S 列失败。

### B 级（形式差异，不影响正确性）

**B1. 构造 B / E 未显式化**

论文的构造 B（单顶针 + 连续 T/P 列）和 E（弱下落）在实现里**没有独立的构造名**，
它们是写进前态生成器的：托柱的针位、以及"某层放针让材料落一层"都是 E 的手工应用。
→ 对产物无影响，但 UI/文档里对不上论文的构造编号。

**B2. 构造 F 带「先顺转 k 个象限」**

论文的构造 F 直接沿环摆 `N | A | B | E` 四列；实现需要先把目标转到半破轴附近
（`cT.T.c` @6 顺转 1、@8 顺转 2）。等价，但多了一步摆位。

**B3. 两刀配方（5 例）**

`.TT.c`、`cTT..T.c` 这类有多个"互相依赖的落点"的角，实现是「装桥柱 → 切 → 重装桥柱 → 再切」。
论文的构造 D 本来就是"一次删一个段"，所以**语义一致**；只是 UI 上会出现两个 `PreState`。

**B4. 第三象限的满高普通柱**

实现常用"第 3 象限满高普通柱"把刀口隔开。论文的构造里没有这根柱，
但实测它是**冗余的**（§4.13：清空后 5 个例子全部仍成立）。
→ 建议生成器优先留空，减少材料。

### C 级（超出论文，但是好的超出）

**C1. 半边工序的第 3 候选**

论文算法 8 只有两个候选（第一候选"目标自身"、第二候选"联合逆提升"）。
我们实测 `cT.T.cPT` 这类角**两个候选都拒绝、但半边确实可得**，
所以补了 `TempCrystalFuse`（临时晶体 + 保险丝柱）。实现里三个候选都在：

```
HalfCandidate = { Algo8Self, Algo8Uplift, TempCrystalFuse }
```

→ 这不是偏离，而是**补全**：论文算法 8 相对定理 6 不完备。

**C2. Rank 语义**

实现只统计一次顶针（`Rank`），托柱里的针算前态的一部分。论文没有 rank 概念
（那是 TMAM 的）。属于我们的扩展，文档需注明。

## 4. 一句话结论

**判据与构造层面已经和论文对齐**（改完 Cut/Collapse 之后连步骤粒度也一致了）；
**剩下的差异集中在三处**：`FillBreak` 这个非论文构造、辅助列留洞、以及 `P.T..c` 一个覆盖缺口。
另外两处是"超出论文"（半边候选 3、Rank），需要在文档里注明来源。
