# 角工序：优选算法 O 与可行算法 F（供「O 的失效边界」分析）

> 2026-11-16。**本文只描述两套算法与全部变量，不做推理。**

---

## 0. 目的（写给推理方）

### 0.1 背景

- **算法 F（可行解）**：来自论文《Shapez 2 列与可分形状的判定和构造》的算法 5 / 算法 6。
  它**已被证明覆盖所有可行解**（论文定理 1/2/3 + 实现全量回归：3–9 层全部 S 列都能生成工序）。
- **算法 O（更优解）**：本会话另设计的路线，目标是
  **1 次顶针 + 0 次弱落 + ≤3 根辅助列**。
  它在已测语料上全部通过，但**没有覆盖性证明**。

### 0.2 要回答的三个问题（本文不回答）

| # | 问题 |
|---|---|
| **Q1** | 算法 O 在什么条件下会**产出不通过回放的工序**？（列出失效条件的完整刻画） |
| **Q2** | 是否存在某个**合法且可制作**的列（S 列），使 **O 解不出、F 解得出**？<br>若有，给出**最小反例**（层数最少、晶体数最少）。 |
| **Q3** | 若存在这样的反例，能否把 O 的适用条件写成**可判定的谓词** $P(t)$，使得 $P$ 真 ⟺ O 可解？ |

### 0.3 为什么值得问

- O 的步骤数、弱落次数都远少于 F（F 可能有多轮弱落，见 §4.2），
  但若 O 有**未知的失效族**，主智能体就需要在运行期判断「该走 O 还是 F」；
- 若 O 的失效族可以刻画成谓词 $P(t)$，就能**先判后造**，不必「先试 O 再回退 F」。

### 0.4 判定的技术前提

- 一切「能不能做出」都用**真实物理回放**判定，不看论文条文；
- 回放算子见 §2.4；
- 一个工序「通过」= §2.5 的五条验收全过。

## 1. 记号与变量（本文出现的全部符号）

### 1.1 图形与层号

| 记号 | 含义 |
|---|---|
| $n$ | 象限数（本文只讨论 $n=4$；$n\ge 6$ 走算法 F 的另一支） |
| $L$ | 图形的层数上限（= 输入图形的层数） |
| $\mathrm{cap}$ | 顶针的层数上限（= $L$，测试里恒等于层数） |
| $k$ | 层号，**从 1 开始**，1 = 地面 |
| $t[k]$ | **目标列**在第 $k$ 层的单元；$t$ 是长度 $\mathrm{cap}$ 的串 |
| 单元 | `.` 空 · `T` 普通格 · `c` 晶体 · `P` 顶针 |
| $H$ | 目标列的目标高度 = 「最高的非空层」 |

### 1.2 目标列的结构量

| 记号 | 定义 |
|---|---|
| **晶体层集合** $C$ | $\{\,k \mid t[k]=c\,\}$ |
| **晶体段** | $C$ 中**极大连续**的一段 $[a,b]$（相邻层号都属 $C$） |
| $f_0$ | **最低晶体层** = $\min C$（若 $C=\varnothing$，走「构造 C」，不进本文） |
| **针段（底针）** $m$ | 目标列**从第 1 层起连续为 `P`** 的个数；$m=0$ 表示 L1 不是针 |
| **尾部** | 高于 $H_c$ 的所有格子（见 1.3），可为空 |
| **主体** | 目标列去掉尾部、再去掉底部 $m$ 枚针之后剩下的列 |
| **洞** | 目标列里为 `.` 的层 |
| **晶下间隙** | 存在 $k\in C$ 使 $t[k-1]=\texttt{.}$（$k>1$）；即某颗晶体正下方是空 |

### 1.3 整图量（与「剥尾」有关）

| 记号 | 定义 |
|---|---|
| $H_c$ | **整图**（$n$ 列）里最高的晶体所在层 = $\max\{\,k \mid \exists\text{列 }j,\ \text{shape}[k][j]=c\,\}$ |
| **尾部** | 那 $n$ 列在 $H_c+1\ldots L$ 上的所有格子（逐层保存） |
| **核心图** | 整图截断到 $H_c$ 层 |

> 注意：$f_0$（最低晶体层）与 $H_c$（整图最高晶体层）是两个不同的量。

### 1.4 施工用的四列（构造 H）

| 记号 | 全称 | 角色 |
|---|---|---|
| $A$ | 目标列的前态（**第 1 象限**） | 施工形态，最后变成目标角 |
| $B$ | 晶体桥柱（**第 2 象限**） | 把临时晶体接到刀口另一侧；按 $I$ 放晶体 |
| $E$ | 满高纯晶体柱（**第 3 象限**） | 引爆柱；顶针时顶端超限整根碎掉 |
| $N$ | 针槽柱（**第 4 象限**） | 决定哪些格下降；按 $J$ 放针 |

> 四个象限的编号：从 $A$ 起顺时针 $A\to B\to E\to N$（论文构造 H 的「四象限环」）。

### 1.5 降表与两个层号集合

| 记号 | 定义 |
|---|---|
| **顶针后层号** | 顶针把每格上移一层，所以「顶针后第 $k$ 层」= 「前态第 $k-1$ 层」。<br>**$I$、$J$、$s$、$d$ 全部用顶针后层号。** |
| $s$ | **源层**：某个要下降的普通格在**顶针后**所在的层 |
| $d$ | **落点层**：同一格在**目标**里所在的层（$2\le d<s\le \mathrm{cap}$） |
| **通道** | 区间 $[d,\ s-1]$（含两端），长度 $s-d$ |
| $I$ | $\bigcup_{\text{每条下降}}[d,s-1]$ ∪ { 每个临时晶体段在**顶针后**的最上层 } |
| $J$ | $\{\,s \mid \text{每条下降的源层}\,\}$ |
| $\mathrm{BTop}$ | $\max\big(\max I,\ \max J-1\big)$：$B$ 只做到这一层，**以上留空** |
| $\mathrm{NTop}$ | $\max\big(\max J,\ \text{最高原生晶体目标层}-1\big)$：$N$ 只做到这一层，**以上留空** |
| $z$ | 辅助列的层号（顶针前），$z=1\ldots\mathrm{cap}$ |

> 「最高原生晶体目标层」= $C$ 的最大值（即 $t$ 里最上面那颗晶体所在的层）。

### 1.6 临时晶体

| 记号 | 定义 |
|---|---|
| **临时晶体** | 前态 $A$ 里**为了填洞而放**的晶体；它在施工中被碎掉，不进入产物 |
| **临时晶体段** | 前态 $A$ 里**极大连续**的一段临时晶体 |
| **空段** | $A$ 里一段连续空层，且其**下方有格、上方有格** |

### 1.7 施工算子与状态谓词

| 记号 | 定义 |
|---|---|
| $\mathrm{Pin}(X)$ | 顶针：每个「第 1 层非空」的列在 L1 补一枚针，全体内容上移一层；顶针后顶端越界的晶体连通块整块删除；再坍落 |
| $\mathrm{Cut}(X)$ | 半破：沿 $n/2$ 对称轴切开，只保留「保留侧」；跨界晶体连通块被删除；再坍落 |
| $\mathrm{Collapse}(X)$ | 坍落：重复「下方为空则下移一层」直到稳定 |
| $\mathrm{Stack}(X,Y)$ | 堆叠：把 $Y$ 的材料堆到 $X$ 上（逐格） |
| **稳定** | $\mathrm{Collapse}(X)=X$ |
| **合法（五项）** | 论文定理 1 的五项条件（针有支撑 / 晶体下的针只在底针段 / 非最高晶体有上盖 / 晶下洞需一枚普通格 / 晶间洞需两枚普通格） |
| **S 判据** | $n=4$：五项 ∧ ($D$ ∨ $F$)；$n\ge6$：五项。$D$、$F$ 见论文定义 6、7 |
| **P1** | 初始前态里每颗晶体正下方都是普通格（不能是空，也不能是临时晶体） |

### 1.8 「工序」的结构

```
工序 = [PreState] [Cut 或 Pin] … [Support] [Collapse] … [Stack × 尾部层数] [Target]
每个 Step 记录：Kind、Title、Shape（该步之后的完整 4 列图形）
```

## 2. 输入 / 输出 / 判定

### 2.1 输入

```
SolveCorner(shape, column, cap)
   shape  : n×L 的单元矩阵，shape[k][j]（k=1..L，j=1..n）
   column : 目标列编号（1..n）
   cap    : 顶针层数上限，本文恒 = L
```

### 2.2 输出

```
成功 ⇒ 工序（步骤序列），且 §2.5 五条全过
失败 ⇒ Uncovered（附中间值），**不允许返回不可制作的结论**（除非五项不成立）
```

### 2.3 顶层判定

```
1) 五项(t) 不成立 ⇒ NotProducible
2) S 判据不成立  ⇒ NotProducible
3) 否则必须能生成（这是 F 的保证）
```

### 2.4 回放算子（判定用）

| 算子 | 语义（逐格，真实物理） |
|---|---|
| $\mathrm{Pin}$ | ① 对每列 $j$：若 $X[1][j]\ne\texttt{.}$，则 $Y[1][j]=\texttt{P}$，内容上移；② 越界（$>\mathrm{cap}$）的晶体连通块整块删除；③ 坍落 |
| $\mathrm{Cut}$ | ① 沿半破轴分成两半；② 跨界的晶体连通块删除；③ 保留「保留侧」；④ 坍落 |
| $\mathrm{Collapse}$ | 反复「某格下方为空则下移一层」，直到不动 |
| $\mathrm{Stack}$ | 新列 = 底层列 + 上层列（上层置于其上） |

### 2.5 「通过」的五条验收

```
1) 初始前态：每颗晶体下方非空（P1）；每条辅助列连续接地、无洞
2) 前态四列过五项，且整体稳定
3) 每一步与真实算子逐格一致
4) 顶针/半破后 col0 逐格 == 目标（中间态允许晶下间隙）
5) 尾部逐层 Stack 之后 col0 逐格 == 目标
```

## 3. 算法 O（优选解）

**目标**：1 次顶针、0 次弱落、≤3 根辅助列。

### 3.1 前置条件

```
n = 4；五项(t) 成立；S 判据成立；C ≠ ∅
```

### 3.2 步骤

```
① 剥尾
   Hc = 整图最高晶体层
   尾部 = 各列在 Hc+1…L 的格子
   核心图 = 截断到 Hc 层

② 数底针
   m = 目标列从 L1 起连续为 P 的个数

③ 取主体
   t = 目标列去掉尾部、去掉底部 m 枚针

④ f0 = t 的最低晶体层

⑤ 逐格放置 A
   对每个 k = 1…cap：
     k <  f0 → A[k]   = t[k]
     k >= f0 → A[k-1] = t[k]
   修正 a：「最低晶体正下方就是材料」时，那枚普通格也下移一格
            （下移边界外扩到整段连续材料块）
   修正 b：深间隙 —— 该普通格抬到「让通道 [d,s−1] 正好覆盖临时晶体段」的位置
            抬升量 = 通道长度 − 1

⑥ 第 1 层
   t[1] = P  ⇒ A[1] 必须非空
   t[1] ≠ P  ⇒ A[1] 必须为空
   底部 m 枚针：A 里只放 m−1 枚

⑦ 临时晶体填充
   A 里每个「空段」⇒ 填临时晶体；被填段上方的格抬到段顶
   每个要下降的普通格在 A 里是【独立的一枚 T】，两枚之间用临时晶体隔开

⑧ 降表与辅助列（顶针后层号）
   对每个「顶针后需要下降」的普通格：
        s = 该格顶针后的层号
        d = 该格在目标里的层号
    J    = { s }
    I    = ∪[d, s−1] ∪ { 每个临时晶体段顶针后的最上层 }
    BTop = max(max I, max J − 1)
    NTop = max(max J, max C − 1)
    B[z] = (z+1 ∈ I) ? 晶体 : 普通格，z ≤ BTop（以上留空）
    N[z] = (z+1 ∈ J) ? 针   : 普通格，z ≤ NTop（以上留空）
    E[z] = 晶体，z = 1…cap
    第 3 象限 = 空（E 占第 3 象限；A/B/N 各占 1/2/4）

⑨ 施工
   X = A|B|E|N
   Y = Pin(X)
   若 m > 0：Y 已补回 1 枚针，剩 m−1 枚需再顶（每次 Pin 再补 1 枚）
   Z = 接尾(Y, 尾部)：自下而上逐层 Stack，每层前先把托柱加高到该层
```

### 3.3 O 的可失败点（显式列出，供 Q1 使用）

| 编号 | 失败点 | 触发方式 |
|---|---|---|
| **O-1** | ⑤ 下移越界：$k\ge f_0$ 且 $k-1<1$ | 最低晶体在 L1 且该格需要下移 |
| **O-2** | ⑤ 修正 b 抬升越界：抬升后超过 $\mathrm{cap}$ | 深间隙且上方材料紧贴 cap |
| **O-3** | ⑥ 第 1 层冲突：算出的 $A[1]$ 与「$t[1]$ 是否 P」冲突 | e.g. $t[1]=\texttt{P}$ 但下移后 L1 为空 |
| **O-4** | ⑦ 空段不存在 / 填充后仍不满足 P1 | 晶体下方找不到可放材料的位置 |
| **O-5** | ⑧ 通道越界：$s-1>\mathrm{cap}$ | 源格在 cap 层 |
| **O-6** | ⑨ 顶针后 col0 ≠ 目标 | 落差不对、通道覆盖不全、辅助列高度错 |
| **O-7** | ⑨ 接尾后 col0 ≠ 目标 | 尾部高度 / 托柱高度不对 |

### 3.4 O 的已知覆盖（回归）

已逐格实测通过（详见 `angle-work-order-general-algorithm.md` §0.8）：

```
.T.c  .T..T..c  T..T...c  T...cT.T.c  T..cT.T.c
P.T..c  ..T.cc  ..T.cTc  P.T...c  P.T...c.
..T..cTc  P.T.T..c  PP.T.cTc  P.T.T..cP  T.T.cccTc
T.T.c  .T.T.c  .TT.c（新，一次顶针）
```

## 4. 算法 F（可行解，论文原样）

### 4.1 算法 5（底格是针）

```
1. 对核心执行【算法 1】：每个「晶体下洞」把最近的普通格提高一格
   ⇒ 正规列 v + 恢复表 M = { s_i → d_i }
2. 把 v 的空填成临时晶体，【去掉一枚底针，整体层号减一】，
   用紧列和其余底针制造所得列（前态里已有 m−1 枚针）
3. 构造 H：J = { s_i }；I = ∪[d_i, s_i−1] ∪ { 每段临时晶体的顶格 }
4. 顶针一次：补回所欠的底针，同时碎临时晶体、完成全部恢复下降
5. 清理辅助件，恢复普通柱
```

### 4.2 算法 6（底格非针、$D$ 成立）

```
第一步 底块提升（至多两次）
   只要最底两层还没都空：
     ① 找「最下方非空位置起的最大连续普通块」
     ② 整块沿上方空段尽量上移，直到紧贴下一份材料
     ③ 记录：块的原区间、上移距离、每格标签
   ⇒ 记录序列 B1、B2

第二步 正规化 + 底格恢复方式
   ① 算法 1 ⇒ 正规列 v + 恢复表 M
   ② 最后一次提升的底块，在 v 中保持整理完成时的位置
   ③ 决定：
        · 无底块提升         → 用 M
        · 最后一块原从 L1 起 → 先执行 M，之后整块弱落回去
        · 最后一块原从 L2 起 → 设现最低格在 b 层，加一条 b→2，记作 e

第三步 提前弱落
   若没有 e ⇒ 跳过
   若有 e   ⇒ 查 M 每条 s→d：若 v 中「s 层以下最近的那枚普通格」正是 b 层那枚 ⇒ 这条提前
                （至多一条，落点 b+1）

第四步 正向制作
   ① 制作 v【整体低一层】的带柱形状（顶部留一层空位）
   ② 执行第三步的提前弱落（源层、目标层号都减一）
   ③ 构造 H 的下降表 = M 去掉提前那条 + e（如有）
        此时临时晶体已删 ⇒ I 只含通道
   ④ 顶针一次
   ⑤ 按底块提升的【逆序】恢复各块；块内从最低格到最高格依次弱落
```

### 4.3 弱落（构造 E）

```
选中目标列第 s 层的一枚普通格：
1. 目标另一侧装一根连续接地的辅助列，仅第 s 层为针，其余普通格
2. 去掉原普通柱，只保留目标与辅助列
3. 第 s 层失去侧向粘连 ⇒ 下落，一直落到同列最近的下方材料之上（或地面）
   它正上方紧接的连续针链也随之下降；其余材料不动
4. 装回普通柱，去掉辅助列
```

### 4.4 算法 F 的覆盖性

论文定理 1/2/3 保证「合法 + S ⇒ 可制作」，算法 5/6/4 给出构造；
实现侧全量回归：3–9 层全部 S 列均能生成工序。

## 5. 两者的关系（事实陈述，不含推理）

| 项 | 算法 O | 算法 F |
|---|---|---|
| 顶针次数 | 1（+ 底针数 −1） | 1（算法 5）/ 1（算法 6） |
| 弱落次数 | **0** | ≥0，可能 2 次以上 |
| 底块提升 | **不做**（用 ⑤ 的「下移」代替） | 显式做，最多 2 次，且**记录块** |
| 偏移量 e | **不引入** | 第二步引入 |
| 提前弱落 | **不引入** | 第三步可能引入 |
| 辅助列 | 3 根（B/E/N），B/N 截断 | 3 根，全高 |
| 覆盖性 | 未证明 | **已证明** |

**关键差异**：O 用「一个聪明的前态」把 F 的「底块提升 + e + 提前弱落 + 逆序恢复」
一次性吸收进前态；代价是**前态必须存在**。F 不依赖聪明前态，靠多轮弱落补齐。

## 6. 交给推理方的问题（再列一次）

### Q1 —— O 的失效条件

§3.3 列了 O-1…O-7 七个失败点。请判断：

- 哪些失败点**必然导致 O 无解**，哪些**只是当前实现的写法不够聪明**（换一种前态就能过）？
- 是否存在 §3.3 之外的失败模式？

### Q2 —— 最小反例

找一列 $t$，满足：

```
五项(t) ✔   且   S 判据(t) ✔   且   O 无法生成通过回放的工序   且   F 能
```

要求：层数最少；同等层数下晶体数最少。

已知的候选方向（**未验证**，仅供参考）：

```
· 有多段短晶体、且每段下方都有洞（O 的「抬升量 = 通道长度 − 1」可能互相冲突）
· 底针 m ≥ 2 且中间夹晶体（O 只放 m−1 枚针，位置可能不够）
· 尾部含针 且 核心的最低晶体在 L1（O-1 + 剥尾同时触发）
· 深间隙 ≥ 3 层且 cap 很紧（O-2/O-5）
```

### Q3 —— 判定谓词

若 Q2 有反例，请尝试给出可判定谓词 $P(t)$，使得 $P(t)$ 真 ⟺ O 可解。
建议形式：

```
P(t) = 五项(t) ∧ S(t) ∧ ¬(条件A) ∧ ¬(条件B) …
其中每个条件只依赖 t 的层号、晶体段长度、洞的位置、m、Hc
```
