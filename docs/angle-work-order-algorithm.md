# 角工序解析算法（整理版）

> 范围：**单个角（一列）的制作路径**——输入目标图形 + 列号 + cap，输出可执行的列级步骤。
> 依据：论文《Shapez 2 列与可分形状的判定和构造》的判据与构造 A–H；
> 具体配方由开发者给出并在 `ShapeEditor.Core` 上逐格实测。
> **全部算法化，没有任何按 `n × 层数` 的查表。**

---

## 0. 术语

| 记号 | 含义 |
|---|---|
| `.`/`T`/`P`/`c` | 空 / 普通格 / 顶针 / 晶体（列字符串左端是地面） |
| 晶体段 | 同列最大连续晶体（颜色不同也算连续） |
| 核心 / 尾部 | 最高晶体及其以下 / 其上方 |
| 紧列 | 从地面连续、只含 `T`/`c` 的列 |
| 托柱 | 目标列旁边那根用来支撑的列（可以不是满高的实心柱） |
| 桥柱 | 碎晶时用来把晶体连通块接到刀口另一侧的辅助列 |
| S / L | 带普通支柱列 / 合法列（见规格 §2） |

## 1. 判定层（先判后造）

### 1.1 五项条件 → 角合法

```
一、针有直接支撑：每枚针接地，或同列正下方非空
二、晶体以下的针只能在底部连续针段中
三、非最高晶体有上盖：上方还有晶体 ⇒ 正上方一格非空
四、晶体下洞需要普通资源：晶体下方有空 ⇒ 下方至少一枚 T
五、晶体之间的洞需要两枚普通资源：两晶体之间有洞 ⇒ 严格之间至少两枚 T
```

五项任一失败 ⇒ **不可制作**（这是唯一的否定判据）。
与 `ShapeAngleAnalyzer` 的四条规则等价（1–8 层枚举计数一致）。

### 1.2 分类

```
最高晶体以下没有空位   ⇒ Simple（不需要碎晶）
否则                  ⇒ NeedsCrystalBreak
没有晶体              ⇒ Simple
```

判定只看最高晶体**以下**；最高晶体上方的尾部留空不影响分类。

### 1.3 n = 4 的附加判据

- **D**：没有晶体 / 最底格是针 / 最低晶体以下至少两个空格。
- **F**：每个「正下方为空的晶体段底端」要么三连晶以上（环下落），
  要么与下方最近晶体之间存在相邻 `TT`（弱下落终点）；下方没有晶体时允许以第 1 层的 `T` 为终点。
- **S ⟺ 五项 ∧ (D ∨ F)**（n ≥ 6 时 S ⟺ 五项，不需要 D/F）。

### 1.4 其它形态

- **孤立列**（成品只有这一列）：连续接地 + 晶体以下的针全是底部针段。
- **n = 2**：可分 ⟺ 左右两列都是孤立列。

## 2. 分档：选哪条算法

**按分档选，不按“哪个步骤少”选。** 分档只依赖列内容与 `n`，与层数无关（见 §10）。

```
角
├─ 无晶体            → 构造 C（逐层追加 T/P）
├─ Simple            → 构造 A（紧列）+ 构造 C（尾部）
└─ NeedsCrystalBreak
   ├─ n ≥ 6          → 算法 1（提升）→ 算法 2（正规核心）→ 算法 3（构造 F 送回）
   └─ n = 4
      ├─ 底格是针     → 算法 5（临时晶体 + 一次顶针批量恢复）   ← 先于下一条
      ├─ D 成立       → 算法 6（底块提升 → 构造 H → 恢复）
      └─ 其余         → 算法 4（递归提升 + 构造 G 环下落；需 F 成立）
```

**两条顺序约定**：

1. 「底格是针」**优先于**「D 成立」——所以 `P.T.c` 走算法 5，不是 6；
2. 分档选出的算法若**在当前 cap 下回放失败**（典型：目标晶体在顶层、顶针会把它顶出 cap），
   才退到等价路线，且必须在 `Note` 里写明
   「分档算法 X 因 cap 不足退化为 Y」：

```
算法 6 失败  → 退 算法 2（正规核心）+ 构造 D（定向碎晶）   ← 见 §4.6
算法 4 失败  → 退 算法 5 / 多轮构造 G
```

**实测的六个角**：`.T.c`、`T.T.c`、`.T..c`、`.T.T.c` 走算法 6；`P.T.c` 走算法 5；
`.TT.c` 的 D 同样成立（算法 6），但它的晶体在顶层、cap = 层数时会被顶针顶掉，
所以实测退到「算法 2 + 构造 D」——这正是上面第 2 条约定的适用场景。

## 3. 构造原语（论文 A–H，角工序用得到的那几个）

| 构造 | 作用 | 在角工序里的角色 |
|---|---|---|
| **A 紧列** | 从地面连续、只含 `T`/`c` 的列，逐层堆 + 单格结晶 | 造前态的主体 |
| **B 单顶针 / 连续 T-P 列** | 满层普通 → 顶针 k 次 → 结晶 → 再顶针一次整簇碎 → 只剩底针 | 造托柱里的针 |
| **C 支柱交接** | 先装新柱、再拆旧柱；追加无晶体尾部时逐层堆 | **收尾**：换托柱、清辅助列 |
| **D 定向碎晶** | 另一侧装辅助列（仅第 k 层晶体），切线穿过该晶体连接 ⇒ 整段碎 | **碎晶角**里删临时晶体 |
| **E 弱下落** | 辅助列仅第 s 层为**针**，去掉原柱 ⇒ 该层失去侧向粘连、向下落 | **让指定格落一层**（托柱里的针） |
| **F 受控下落**（n≥6） | 针槽柱 N + 辅助柱 B + 碎晶桥柱 E，落到指定层 d | n≥6 的送回 |
| **G 单孔环下落**（n=4） | 目标与辅助列成环，碎桥柱晶体 ⇒ 只降一层 | 精度比 E 高的替代 |
| **H 一次顶针批量下落**（n=4） | 目标 A / 晶体桥柱 B / 纯晶柱 E / 针槽柱 N，一次 Pin 同时完成整组下降 | **塔式路线的主体** |

## 4. 已实测的配方

约定：`前态的 col0` 是目标列的施工形态；`顶针(col0)` 是 Pin 之后该列的样子；
全部用真实 `ShapePhysics` 逐格验证过。

### 4.1 `.T.c`（4 层，算法 6）

```
前态 col0 = .Tc.    顶点：晶体下移一层，直接坐在 T 上
X = --cgcgCu:CuCucgP-:cr--cgCu:----cg--
顶针(X) col0 = .T.c  ✔
```

### 4.2 `T.T.c`（5 层，算法 6）

```
前态 col0 = .TTc.   底块提升：两个 T 上移、缺口封上
X = --CucrP-:CucrcrP-:CuCucrP-:cr--crCu:----cr--
顶针(X) col0 = T.T.c ✔
追加：第二象限堆叠 TT 补支撑（构造 C 的「追加材料」）
```

> `T.T.c` 还有一条**不用顶针**的碎晶路线，见 §4.6（同一个 `cTcTc` 骨架、同一组两刀，
> 只需把托柱第 2 层也换成针）。

### 4.3 `P.T.c`（5 层，算法 5）

```
前态 col0 = ccTc.   底针位置先用临时晶体顶住（算法 5 第二步）
X = crcrcrP-:crCucrP-:CuCucrP-:cr--crCu:----cr--
顶针(X) col0 = P.T.c ✔
```

### 4.4 `.T..c`（5 层，算法 6）

```
前态 col0 = ..Tc.   晶体下移贴住 T；**不含 `.T.c` 子形态**（避免自递归）
X = --crcrCu:--crcrCu:CuCucrP-:crCucrCu:----cr--
顶针(X) col0 = .T..c ✔
```

### 4.5 `.T.T.c`（6 层，算法 6）

```
前态 col0 = .T.Tc.  晶体下移一层、最后一个缺口封上
X = --crcrP-:CuCucrP-:--CucrP-:CuCucrP-:cr--crCu:----cr--
顶针(X) col0 = .T.T.c ✔
```

### 4.6 `cTcTc` 骨架族：`.TT.c` 与 `T.T.c`（**等价路线**：算法 2 + 构造 D×2 + E + C）

> **这不是首选路线。** 按 §2 的分档，`.TT.c` 与 `T.T.c` 的 D 都成立，首选 **算法 6（顶针）**；
> 本节的两条碎晶配方是**算法 2 + 构造 D 的等价替代**，只在
> 「算法 6 在当前 cap 下回放失败」时使用（`.TT.c` 的晶体在顶层，cap = 层数时会被顶针顶掉，
> 就是这种情况）。`T.T.c` 走算法 6 已经实测通过，**按分档应优先用它**。

**两个角共用同一个骨架与同一组两刀，只有托柱的针位不同。**

```
骨架  cTcTc = c T c T c
L5  c  .  T      ← 桥柱与托柱在右侧（下图展开四列）

前态（托柱不同 → 结果不同）
L5  c  T  .  T
L4  T  P  .  T     ← 托柱第 4 层：两种都放针
L3  c  T  .  c     ← 桥柱晶体（第 3 层）
L2  T  X  .  T     ← X = 针 ⇒ T.T.c ；X = 普通 ⇒ .TT.c
L1  c  T  .  T
```

第一步：碎中间晶体（桥柱第 3 层放晶体）→ **两角的中间结果相同**

```
col0 = cTT.c        （第 4 层的 T 落回第 3 层）
```

第二步：碎底层晶体（桥柱第 1 层放晶体）

| 托柱 | 第 2 层 | 第 4 层 | 第二刀后 col0 | 目标 |
|---|---|---|---|---|
| `TTTPT` | 普通（托住） | 针（放掉） | `.TT.c` | **`.TT.c`** ✔ |
| `TPTPT` | **针（放掉）** | 针（放掉） | `T.T.c` | **`T.T.c`** ✔ |

**结论：`T.T.c` 也能用切割碎晶做**，它和 `.TT.c` 的差别只是
**托柱在第 2 层是「针」还是「普通格」**——针让第 2 层那格普通格也落一层。

```
.TT.c ：crCu--Cu:CuCu--Cu:crCu--cr:CuP---Cu:crCu--Cu     ← 托柱 TTTPT
T.T.c ：crCu--Cu:CuP---Cu:crCu--cr:CuP---Cu:crCu--Cu     ← 托柱 TPTPT
```

两条路线都实测通过（`稳定 ✔ 每列合法 ✔`，两刀后逐格等于目标）。

**为什么能碎而别的角不能**：填充晶体与目标晶体之间隔着 `T`，不构成同一晶体连通块；
像 `.T.c` 那种填充晶体直接贴住目标晶体的角，一碎就连带（实测得到 `T.T..`）。

**一刀还是多刀**：桥柱在两层都放晶体时**一刀就能炸掉两个连通块**（实测 `.TT.c` 一刀即得目标）；
按论文构造 D 的条文（「选择**一个**最大连续晶体段」）则是逐段一刀。
实现上优先「一刀多段」，炸不干净再退回逐段。

### 4.7 `T.ccc`（5 层，**算法 4**：环下落恢复，已实测）

`T.ccc` 的判据：五项 ✔，**D ✘**（最低晶体下方只有 1 个空），**F ✔**（三连晶 ⇒ 环下落条件）
⇒ 落在 **算法 4**（不满足 D 时，递归提升与环下落）。

论文算法 4 的两条恢复手段：

```
1. 段长 ≥ 3  → 把下方最近的普通格提到晶体正下方，记一次【环下落恢复】
2. 段长 1/2  → 递归提升：把晶体下方最近的普通格提上来，
               看它原位置的正下方：地面/普通 → 停；空 → 再提一格；晶体 → 失败
所有洞处理完后按算法 2 做正规核心，再把普通格从上到下送回（短段弱下落，长段单格环下落）
```

`T.ccc` 走的是第 1 条（晶体段长 3）：

```
目标 T.ccc
  → 提升 T（L1 → L2）        col0 = .Tccc
  → 算法 2 正规核心：填 L1    col0 = cTccc      ← 实测前态
  → 恢复（环下落：让 T 落回 L1）
```

**实测前态**（用户给出）：

```
L5  c  T  .  .
L4  c  P  .  .
L3  c  T  .  .
L2  T  T  .  .
L1  c  c  c  .      ← 第 3 列只在 L1 放一颗晶体，用来把临时晶体接到刀口另一侧
短代码：cgcgcg--:CuCu----:crCu----:crP-----:crCu----

各列：cTccc | cTTPT | c.... | .....
稳定 ✔  每列合法 ✔
半破 → west 第 1 列 = T.ccc ✔（正好是目标）
```

为什么只掉一层：碎掉 L1 的临时晶体后，`T@L2` 与托柱的 `T@L2` 同组、下方无支撑 ⇒ 整组落到 L1；
上面的晶体段（L3–L5）由托柱 L3 的实心格托住、并被 L4 的**针**与下方隔开，保持原位。

> 论文对长段的「恢复」写的是**单格环下落（构造 G）**；这里用**定向碎晶（构造 D）**
> 达到了同样效果——都让 T 恰好落一层。两者可互换，按 cap/辅助列方便程度选。

### 4.8 `cTT.cccT.T.ccc`（**14 层**，算法 4 标准施工）

这一例证明分档对**任意层数**都成立（没有“5 层专用”的特化）。

```
目标列 = cTT.cccT.T.ccc      （14 层）
   五项 ✔   D ✘（最低晶体下方只有 1 个空）   F ✔（长晶体段 ⇒ 环下落条件）   S ✔
   ⇒ 算法 4
```

**算法给出的核心列（两步）**：

| 步 | 动作 |
|---|---|
| ① 提升 | 晶体段底端正下方为空的，把下方最近的普通格提上去 |
| ② 正规核心 | 洞里全部填**临时晶体**，得到紧列，用构造 A 造 |

| 层 | 目标 | 提升后 | 动作 |
|---|---|---|---|
| 3–4 | `T .` | `. T` | T 由 3 提到 4（3 变空 ⇒ 填临时晶体） |
| 9–11 | `. T .` | `. . T` | T 由 10 提到 11（9、10 变空 ⇒ 填临时晶体） |

核心列 = `cTcTcccTccTccc`（临时晶体在第 3、9、10 层，其中 **9 与 10 纵向相邻 ⇒ 同一连通块**）。

**③ 恢复：删临时晶体，从上到下。** 两个连通块 `{L3}`、`{L9,L10}` 分两次删，顺序不能反。

**推荐前态（已实测，四列全部合法）**：

```
crCuCuCu:CuCuCuCu:crCuCucr:CuP-CuCu:crCuCuCu:crP-CuCu:crCuCuCu:
CuCuCuCu:crCuCuCu:cr--Cucr:CuCuCuCu:crCuCu--:crP-Cu--:crCuCu--

col0 = cTcTcccTccTccc      ← 算法 4 的「提升 + 正规核心」结果
col1 = TTTPTPTTT.TTPT      ← 托柱（针在第 4、6、13 层；L11 留空给 T 让位）
col2 = TTTTTTTTTTTTTT      ← 满高普通柱
col3 = TTcTTTTTTcT...      ← 桥柱（第 3、10 层各放一颗晶体）

半破（一刀）→ west col0 = cTT.cccT.T.ccc  ✔
```

一刀同时删掉两个连通块：桥柱在第 3、10 层各放一颗晶体，分别把 `{L3}` 与 `{L9,L10}`
接到刀口另一侧。

**两条实现注意**：

1. **必须走 `Cut`（半破），不能「手工删格 + `Collapse`」**：

   ```
   半破                     → cTT.cccT.T.ccc  ✔
   手工删格 + Collapse       → cTcTcccTT..ccc  ✘（T 从 11 掉到 9，多掉一层）
   ```

   `{L9,L10}` 一起消失后 T@11 下方两格同时空掉；`Cut` 的分半 + 重分组会把落点锁在
   「与托柱同层相接」的位置，而朴素下落会算过头。
2. **算法只规定核心列与恢复顺序，不规定辅助列的布局**——托柱针位、桥柱晶体层位是实现自由度
   （旧版前态 `crCuCu--:...:crCu----` 的托柱 `TTcTTPTTcTTTPT` 甚至不满足五项条件；
   新版四列全合法，应优先采用）。

### 4.8.1 提升不是「提最近一格」就够 —— 需要阶梯式抬升（实测）

目标 `cT.T.T.T...ccc`（14 层，T 在第 2、4、6、8 层，晶体段 12–14 长 3，D ✘ / F ✔ ⇒ 算法 4）：

```
按条文直译（只把 T@8 提到 L11，其余洞填满）：
   核心列 = cTcTcTccccTccc
   删 {L7..L10} + {L3} + {L5}  →  cTTT......Tccc   ✘
```

**直译不成立**。可行的是**阶梯式抬升**——每个 T 抬不同的量，给临时晶体腾位置：

```
目标   cT.T.T.T...ccc        （T 在 2、4、6、8）
前态   cTccTccTccTccc        （T 在 2、5、8、11，分别抬了 1、2、3 层）
       ↑ 临时晶体成对夹在两个 T 之间：T cc T cc T cc T
半破 → cT.T.T.T...ccc  ✔    （实测；前态四列全部合法）
```

前态短代码：

```
crCuCuCu:CuCuCuCu:crCuCucr:cr--CuCu:CuCuCuCu:crCuCuCu:cr--CuCu:
CuCuCuCu:crCuCuCu:cr--Cucr:CuCuCuCu:crCuCu--:crP-Cu--:crCuCu--

col0 = cTccTccTccTccc     col1 = TTT.TT.TT.TTPT
col2 = TTTTTTTTTTTTTT     col3 = TTcTTTTTTcT...
```

**结论**：算法 4 规定的是**不变量与恢复顺序**，不是 scaffold 的唯一形态：

1. 核心列必须是紧列（构造 A 可造）；
2. 每个临时晶体必须能以**连通块**为单位定向删除；
3. 删完后目标材料要落到正确层（托柱针位 / 桥柱位置控制落点）；
4. **其余自由度（抬升多少、填几格）由程序搜索 + 回放验证决定**，
   照抄「提升最近一格」的直译往往过不了回放。

### 4.8.2 同一套辅助列，三种 scaffold（三个 14 层例子）

| 目标 | 前态 col0 | 抬升 | 半破结果 |
|---|---|---|---|
| `cTT.cccT.T.ccc` | `cTcTcccTccTccc` | T@3→4、T@10→11 | ✔ |
| `cT.T.T.T...ccc` | `cTccTccTccTccc` | T@4→5、T@6→8、T@8→11 | ✔ |
| `cT.T....T..ccc` | `cTccTcccccTccc` | T@4→5、T@9→11 | ✔ |

三例的辅助列**完全一致**：

```
col2 = TTTTTTTTTTTTTT      满高普通柱（不动）
col3 = TTcTTTTTTcT...      桥柱：第 3、10 层各一颗晶体
```

只有 `col0`（前态目标列）与 `col1`（托柱针位）随目标变化。这说明：

- **桥柱的晶体层位由「临时晶体块所在的层」决定**（本例都在 L3 与 L9–L10 附近）；
- **托柱的针位由「T 要落回的层」决定**；
- 抬升量、填格数是搜索自由度，方案不唯一，但都要过「半破 == 目标」的回放。

### 4.9 `cTT..T.c`（8 层，**段长 1 ⇒ 递归提升**，已实测）

算法 4 的另一条分支：晶体段长 **1 或 2**，D 不成立、F 成立 ⇒ **递归提升**。
论文自己的例 1 就是这一格。

```
目标列 = cTT..T.c     （8 层）
   五项 ✔   D ✘（最低晶体下方 0 个空）   F ✔（晶体段下方与最近晶体之间有相邻 TT）   S ✔
   ⇒ 算法 4 的递归提升分支
```

**递归提升的推导**（论文原文）：

```
晶体段 {c@8} 长 1，正下方 L7 为空 ⇒ 递归提升
  ① 把下方最近的普通格 T@6 提到 L7
     再看 T@6 原位置的正下方 = L5 → 空 ⇒ 继续
  ② 把下方最近的普通格 T@3 提到 L5
     再看 T@3 原位置的正下方 = L2 → 普通格 ⇒ 结束
提升计划 = c T . . T . T c   （cT..T.Tc）
```

**实测施工（8 层、4 象限）**：

```
目标   cTT..T.c
① 提升  col0 = cT..T.Tc
② 正规核心（洞填临时晶体）：col0 = cTccTcTc      ← 紧列，构造 A 可造
③ 恢复（从上到下删临时晶体，让普通格弱落）：

   托柱 = TTTPPTPT     ← 针在第 4、5、7 层：正是两枚 T 的下落路径
   （托柱本身五项 ✔）

   删 L6 临时晶体          → col0 = cTccTT.c    （T@7 → 6）
   删 L3+L4 临时晶体【整段】→ col0 = cTT..T.c  ✔ （T@5 一次落到 3，被 L2 的 T 挡住）
```

**两个必须注意的物理事实**：

1. **临时晶体要按“连通块整段”删**：`cTccTcTc` 里 L3 与 L4 的晶体**纵向相邻**，
   属于同一个晶体连通块——删 L4 必然连带删掉 L3，不可能只删其中一颗。
   所以这一步是「删 L3+L4 整段」，不是两次删除。
2. **顺序必须从上到下**（论文原话「把普通格从上到下送回」）：

   ```
   先删 L6、再删 L3+L4   →  cTT..T.c   ✔
   先删 L3+L4、再删 L6   →  cTTT...c   ✘（实测）
   ```

   自上而下的顺序保证每一枚普通格落到“还留着临时晶体当刹车”的那一层。

**托柱针位的通用规则**：**被提升的普通格要落回的层 / 它下落路径经过的层，托柱必须放针**；
其余层实心。这里两枚 T 分别从 L7、L5 落回 L6、L3，所以针在 7、5、4（路径上）。

### 4.10 反例：`cT.T.T.c` 不属于算法 4

```
cT.T.T.c = c T . T . T . c
   五项 ✔   D ✘   F ✘   ⇒   S ✘
```

D 不成立（最低晶体下方 0 个空），F 也不成立（晶体段长 1，且它与下方最近晶体之间**没有相邻 TT**），
所以 **S 判据失败**——它是「合法但不可造为带柱列」的形态（论文 §五 的 `cT.T.c` 同类），
不能当算法 4 的例子。

### 4.11 算法 4 的实测方案汇总（可直接使用的短代码）

约定：短代码都是**前态**，`半破` 后 west 第 1 列即为目标角。
`col0` = 目标列的施工形态，`col1` = 托柱，`col3` = 保险丝/桥柱。

| 目标 | 核心列 | 刀数 | 前态短代码 |
|---|---|---|---|
| `T.ccc`（5 层） | `cTccc` | **1** | `crCu--cr:CuP-----:crCu----:crCu----:crCu----` |
| `cT.T.ccc`（8 层） | `cTccTccc` | **1** | `crCuCuCu:CuCuCuCu:crCuCuCu:cr--Cucr:CuCuCu--:crCuCu--:crP-Cu--:crCuCu--` |
| `cTT..T.c`（8 层） | `cTccTcTc` | **2** | 见下 |
| `cTT.cccT.T.ccc`（14 层） | `cTcTcccTccTccc` | **1** | `crCuCuCu:CuCuCuCu:crCuCucr:CuP-CuCu:crCuCuCu:crP-CuCu:crCuCuCu:CuCuCuCu:crCuCuCu:cr--Cucr:CuCuCuCu:crCuCu--:crP-Cu--:crCuCu--` |
| `cT.T.T.T...ccc`（14 层） | `cTccTccTccTccc` | **1** | `crCuCuCu:CuCuCuCu:crCuCucr:cr--CuCu:CuCuCuCu:crCuCuCu:cr--CuCu:CuCuCuCu:crCuCuCu:cr--Cucr:CuCuCuCu:crCuCu--:crP-Cu--:crCuCu--` |
| `cT.T....T..ccc`（14 层） | `cTccTcccccTccc` | **1** | `crCuCuCu:CuCuCuCu:crCuCucr:cr--CuCu:CuCuCuCu:crCuCuCu:crCuCuCu:crCuCuCu:crCuCuCu:cr--Cucr:CuCuCuCu:crCuCu--:crP-Cu--:crCuCu--` |

`cTT..T.c` 需要两刀（一刀在搜索里 0 命中）：

```
前态 1（只碎 L6 的临时晶体）
crCu--Cu:CuCu--Cu:crCu--Cu:crCu--Cu:CuP---Cu:crCu--cr:CuP---Cu:crCu--Cu
   → 第一刀 → col0 = cTccTT.c

前态 2（再把 L3+L4 的临时晶体接上桥柱；拖柱沿用第一刀后的形态）
   col3 = TTcccTTT（第 3、4 层放晶体）
   → 第二刀 → col0 = cTT..T.c  ✔
```

**为什么这一格一刀不行**：两个落点互相干扰——
`T@7` 要落到 `L6`（落在还留在 `L5` 的 `T@5` 上），而 `T@5` 同时又要落到 `L3`。
如果两组临时晶体在同一次坍缩里消失，`T@5` 先离开 `L5`，`T@7` 就会继续掉到 `L3`。
所以必须**上先下后**分成两刀。

### 4.12 一刀还是多刀：判定规则

```
把要删的临时晶体块按「落点」分组：
  若两个落点的下落路径互不重叠              → 一刀（一刀多段）
  若上面的落点依赖下面的材料「还在原位」挡着 → 必须分刀，且顺序从上到下
```

- `cTT.cccT.T.ccc` 的两个块 `{L3}`、`{L9,L10}` 落在互不重叠的区间 ⇒ 一刀 ✔；
- `cTT..T.c` 的上段落点压在下一段的材料上 ⇒ 两刀，上先下后 ✔。

这条与 §5 规则三（临时晶体按连通块整段删、从上到下）是同一件事的两种说法。

### 4.13 第三象限是冗余的（实测）

半破只保留 west 半边（第 1、2 象限），**第 3、4 象限都会被丢弃**；
第 3 象限只是当初为凑稳定性加的，**可以留空**。实测：把 col2 清空后，5 个例子全部仍然成立。

| 目标 | 清空第三象限后 | 简化短代码 |
|---|---|---|
| `cT.T.ccc`（8 层） | ✔ | `crCu--Cu:CuCu--Cu:crCu--Cu:cr----cr:CuCu----:crCu----:crP-----:crCu----` |
| `cTT.cccT.T.ccc`（14 层） | ✔ | `crCu--Cu:CuCu--Cu:crCu--cr:CuP---Cu:crCu--Cu:crP---Cu:crCu--Cu:CuCu--Cu:crCu--Cu:cr----cr:CuCu--Cu:crCu----:crP-----:crCu----` |
| `cT.T.T.T...ccc`（14 层） | ✔ | `crCu--Cu:CuCu--Cu:crCu--cr:cr----Cu:CuCu--Cu:crCu--Cu:cr----Cu:CuCu--Cu:crCu--Cu:cr----cr:CuCu--Cu:crCu----:crP-----:crCu----` |
| `cT.T....T..ccc`（14 层） | ✔ | `crCu--Cu:CuCu--Cu:crCu--cr:cr----Cu:CuCu--Cu:crCu--Cu:crCu--Cu:crCu--Cu:crCu--Cu:cr----cr:CuCu--Cu:crCu----:crP-----:crCu----` |

**但第二象限的两个特征缺一不可**（同一批实测，以 `cT.T.ccc` 为例）：

| col1 | 结果 | 结论 |
|---|---|---|
| `TTT.TTPT`（针 L7 + 洞 L4） | `cT.T.ccc` ✔ | 基准 |
| `TTTTTTPT`（只有针） | `cT..Tccc` ✘ | T@5 没落 |
| `TTT.TTTT`（只有洞） | `cT.T....` ✘ | 上面的晶体段整段掉了 |
| `TTTTTTTT`（全 T） | `cT..Tccc` ✘ | 等于没有机关 |

所以「托柱」的最小形态是：**在环里放一颗针 + 在环下方留一个洞**，
其余层实心——两个都要，缺一即失效。

## 5. 通用构造规则（五条）

**规则一：要让某格下落一层 ⇒ 把托柱在“那一层”换成顶针。**
顶针不参与横向粘连，该层就不提供侧向支撑；其余层仍是实心，别的格照旧被托住。
这就是构造 E（弱下落）的逐层版本——`TTTPT` 里的那个 `P` 只让第 4 层那格掉；
`TPTPT` 有两个 `P`，就让第 2、4 层两格各掉一层。
**同一条规则换个针位，就是另一个角**（`.TT.c` ↔ `T.T.c`，见 §4.6）。

要让一格**跨多层**落回去，则**整条下落路径上的每一层都要放针**——
`cTT..T.c` 的托柱 `TTTPPTPT`（针在第 4、5、7 层）就是因为两枚 T 要走 7→6 和 5→4→3（§4.9）。

**规则二：要在晶体正下方造洞 ⇒ 先把该格“下移/抬升”错开，再填晶体。**
晶体纵向融合：填充晶体若直接贴在目标晶体下方，碎它必然连带炸掉目标。
错开一层之后才可能单独炸（`.TT.c` 的 `cTcTc` 就是这么来的）。

**规则三：临时晶体按「连通块」整段删，删的顺序从上到下。**
相邻的临时晶体会纵向融合成一个连通块，**不能只删其中一颗**；
恢复的顺序必须自上而下，因为每一枚普通格要靠“还没删的临时晶体”当刹车停在指定层
（`cTT..T.c`：先删 L6 → 再删 L3+L4 整段 ✔；反过来得到 `cTTT...c` ✘）。

**规则四：切割的保留侧必须同时含「目标列 + 托柱」。**
论文构造 D 的原话是「保留目标和原普通柱，删去辅助列」；
不满足时切完普通格失去托柱、直接落地（实测 `实际列 = TT..c`）。

**规则五：前态不能包含正在求解的那个角。**
`.T..c` 若用 `.T.c.` 当前态，就要再解一次 `.T.c`（多一次顶破）；
用户给的 `..Tc.` 版本可一次成型。

## 6. 验收（六条硬约束）

每生成一张工序单，必须全部通过：

1. **前态每一列都过五项条件**（防止把非法列当起点——`cTcT.c` 就是这样漏过去的）；
2. **前态的目标列 ≠ 目标列**（防止「先做出目标再切柱子」的循环）；
3. 前态、每个中间态都**稳定**；
4. 每一步用真实 `ShapePhysics` 回放：`Cut` / `Pin` / `Stack` 都要逐格等于期望；
5. 最终产物逐格等于目标；
6. 失败必须区分「未覆盖（还没实现）」与「不可制作（五项条件失败）」。

---

## 7. 工序单的数据形状

```
AngleWorkOrder
    Column, Kind, Construction, Steps, Note, Limitations,
    IsComplete, Rotation, AuxiliaryColumns, Rank

AngleWorkStep(Kind, Title, Shape)      Kind ∈ { PreState, Cut, Collapse, Pin, Stack, Support, Target, Note }
```

- `PreState`：前态（含托柱/桥柱/临时晶体）；
- `Cut`：一次半破（含顺转量 `Rotation`）；
- `Pin` / `Stack`：构造 H / 追加材料；
- `Support`：构造 C 的换柱；
- `Target`：清辅助列后的目标角；
- `Rank` **只统计该角自身的顶针操作**（托柱里的针是前态的一部分，不计）。

## 8. 实现注意

1. **先按缺口形态选算法，再动手**，不要一律「填充+暴破」；
2. **分支裁剪**：构造 H 的 `support × block × fuse × 列编码` 是五重枚举，
   不适用时必须先判掉——`.TT.c` 曾因此花掉 **161 ms**（其它角 0.2–6 ms）；
3. 前态的生成要按 §5 的四条规则，不要「照抄目标 + 加柱子」；
4. 所有中间态都要过 §6 的六条，任何一条不过就换分支。

## 9. 未覆盖

> 下面这些是**当前实现**的缺口；§11 给出的通用算法把它们都纳入同一个流程
> （规范计划 + 变体搜索 + 回放），实现后本节应逐步清空。

1. **n ≥ 6 的角工序**：算法 1–3 + 构造 F 的**算法已写**（§12），但尚未实现、无实测样例；
   另外 **n ≥ 6 的 S 判据不能沿用 `PillarSCriterion`**（那是 n = 4 的 D∨F 版本，见 §12.1）；
2. **构造 G（单格环下落）尚未实现**：它是算法 4 对**长段（≥3）**的标准恢复手段，
   能把下落锁成恰好一层；没有它，14 层那类例子只能走碎晶等价路线（§4.8）；
3. **算法 4** 已有两个实测样例：`T.ccc`（段长 ≥3 ⇒ 环下落，§4.7）、
   `cTT..T.c`（段长 1 ⇒ 递归提升，§4.9）；段长 2 的情形与段长 1 同类，可直接复用；
4. **循环支撑结构**：本次范围外；
5. **变体搜索（§11.3）尚未实现**：现在仍是「按形态手工生成前态」，需要改成
   「规范计划 + 有界变体 + 回放验证」。

## 10. 任意层的适配（**禁止打表**）

所有判据与构造只用两种操作：**沿列扫描**、**找最近的材料/空段**。
层号一律是变量，不允许出现「4 象限 5 层专用」的写死分支，也不允许按 `n × L` 建表。

| 步骤 | 怎么算 | 代价 |
|---|---|---|
| 五项条件 | 逐层扫描该列，遇到针/晶体各查一次 | O(L) |
| 分类 Simple / NeedsCrystalBreak | 扫最高晶体以下有没有空 | O(L) |
| **D** | 扫最低晶体**以下**，数空格 ≥ 2 | O(L) |
| **F** | 扫每个「正下方为空的晶体段底端」，找下方最近晶体 + 相邻 `TT` | O(L) |
| **算法 6 第一步：底块提升** | 循环「找最下方非空位置起的最长连续普通块 → 量它上方的空段 → 抬到紧贴下一份材料」，直到最底两层都空；**最多两次**（这条性质只涉及最底两层，与总层数无关） | O(L) 每次 |
| **构造 H** | 下降表 `s → d` 来自提升记录；`I = ∪[d, s−1]`、`J = 源层 s`；托柱第 z 层按 `z+1 ∈ I` / `z+1 ∈ J` 决定放晶体还是针 | O(L · 下降数) |
| **构造 D / E** | 桥柱晶位 = 要碎的段所在层；托柱针位 = 要落的那一格所在层 | O(L) |
| **构造 C** | 逐层追加尾部 / 换柱 | O(L) |

**三条硬性要求**：

1. 任何「第 k 层」都必须由扫描得出（如「最低晶体所在的层」「最下方连续块的上端」），
   不能是常量；
2. 分支条件只允许是 `D`、`F`、`底格是否为针`、`段长是否 ≥ 3` 这类**结构谓词**，
   不允许是「层数 == 5」；
3. 验收用真实物理逐格回放，而不是比对预置答案——否则很容易退化成打表。

单角复杂度最坏 **O(L²)**（每步 O(L)、步数 O(L)），实测 5–6 层都在 10 ms 以内；
规模上去后瓶颈是分支枚举（§8 第 2 条），不是层扫描。

## 11. 通用角工序算法（**不追求最短路径**）

目标：**一个能处理所有情况的算法**。宁可多几步，也要「要么做出、要么明确说未覆盖」，
不允许依赖手写的前态清单。

### 11.1 主流程

```
SolveCorner(target, column, cap):
    if !五项(column)                       → NotProducible          // 唯一的否定判据
    kind = Classify(target, column)
    if kind == 无晶体                      → route = A              // 构造 C
    elif kind == Simple                    → route = B              // 构造 A 紧列 + 构造 C 尾部
    elif n >= 6                            → route = C              // 算法 1 → 2 → 3（构造 F）
    elif column[0] == 'P'                  → route = D              // 算法 5
    elif D(column)                         → route = E              // 算法 6
    else                                   → route = F              // 算法 4（需 F 成立）

    plan = CanonicalPlan(route, target, column, cap)                // §11.2
    foreach θ in Variants(plan):                                    // §11.3
        order = Replay(θ)                                           // 真实物理逐格回放
        if order.IsComplete: return order
    return Uncovered(tried: route, reasons)
```

路线 A / B 不涉及晶体，直接由构造 C / A 生成步骤即可，下面讨论的是 C–F（碎晶角）。

### 11.2 规范计划（CanonicalPlan）——全部由扫描得出

计划是一个参数元组 `θ = (lift, fill, support, bridge, cuts, order)`：

| 参数 | 生成规则（扫描，非查表） |
|---|---|
| `lift` | 对每个「晶体段底端正下方为空」的段：把**下方最近的普通格**提到段底正下方；<br>若该格原位置下方仍为空，段长 1–2 时**继续递归**，段长 ≥3 时停下并记录「环下落」 |
| `fill` | 最高晶体以下的所有空位（正规核心的规范选择 → 紧列，构造 A 可造） |
| `support` | 全实心，**在被提升格的下落路径层放针**（路径 = 原层 −1 到落点层） |
| `bridge` | 每个临时晶体**连通块**取一个锚层（块的最高层），桥柱在该层放一颗晶体 |
| `cuts` | 锚层互不相同 ⇒ **一刀**；否则按锚层分组、**每组一刀**（从上到下） |
| `order` | 从上到下删块（论文「把普通格从上到下送回」） |

生成的核心列即「提升 + 正规核心」，辅助列为：满高普通柱 + 托柱 + 桥柱（§4.8 的三列布局）。

### 11.3 变体搜索（有界、非查表）

规范计划**不保证**一次通过（§4.8.1 的阶梯式抬升就是反例）。失败时按固定顺序枚举变体，
**每个候选都跑一遍真实回放**，第一个通过的即为结果：

```
V1  抬高量：每处提升的落点 k 取 1..(该处的最大可用空段)，按「从近到远」枚举
V2  填充集：规范值（全部洞）/ 只填「晶体正下方」的洞
V3  托柱针位：{落点层} / {原层−1 … 落点层} / 全实心
V4  切割：一刀全碎 / 逐块各一刀（从上到下）/ 逐块各一刀（从下到上）
V5  恢复顺序：从上到下 / 从下到上
```

- 枚举是**字典序 + 预算上限**（建议 ≤ 几百个候选，单候选 O(L²)）；
- 任何候选通过回放即返回，**不比较步数**（不追求最短路径）；
- 变体只改参数，不改构造原语（始终是 A/C/D/E/F/H 那些）。

### 11.4 验收（每个候选都要过）

1. 前态每一列过五项条件；
2. 前态目标列 ≠ 目标列；
3. 每个中间态稳定；
4. 每一步与 `ShapePhysics` 的真实结果逐格一致；
5. 最终列逐格等于目标；
6. 失败分级：`NotProducible`（五项失败）≠ `Uncovered`（计划与变体全试完仍不通）。

### 11.5 为什么这样能覆盖所有情况

- **判据是完备的**：五项条件是必要且充分的可制作条件（论文定理 1）；
- **构造原语是完备的**：A/C 造紧列与尾部、D 定向碎晶、E 弱下落、H 批量顶针，
  覆盖论文全部构造；
- **计划空间覆盖了「提升—填充—删除—落位」的全部自由度**，只要有解，就落在某个 `θ` 上；
- **回放是终审**：不依赖任何预置答案，因此对新层数、新形态天然适用。

代价是「路径可能不是最短的」——这正是允许的取舍：**先保证正确，再谈优化**。

## 12. 象限数 n ≥ 6 的角工序（算法 1 → 2 → 3 + 构造 F）

### 12.1 判据先不同：n ≥ 6 时不需要 D / F

```
n = 4 ：S ⟺ 五项 ∧ (D ∨ F)      （定理 3）
n ≥ 6 ：S ⟺ 五项               （定理 2，L = S = 五项）
```

**实现注意**：现有 `PillarSCriterion.IsPillarColumn(col)` 实现的是 **n = 4** 的判据
（`五项 ∧ (D∨F)`），**不能直接用于 n ≥ 6**。
反例：`cT.T.c` 五项 ✔，但 D ✘、F ✘——n = 4 时不是 S，**n ≥ 6 时是 S**。
n ≥ 6 应直接判五项（或给 `PillarSCriterion` 加 `n` 参数分派）。

### 12.2 算法 1：晶体下洞的普通提升

```
输入：通过五项的列。先保存最高晶体以上的尾部，只处理核心（最高晶体及其以下）。
从下往上扫描晶体段：
    若某段晶体的正下方为空 →
        沿连续空位向下找到最近的普通格 →
        把它提高到这段晶体的正下方，记录 (新层, 原层)
重复到所有晶体都接地或正下方非空。
得到核心列 X，以及恢复表 R = {(新层, 原层), ...}
```

五项条件保证每次提升都有所需的普通格，并保留下方晶体的必要上盖。
**每次只提一格**，与 n = 4 的算法 4 不同——n ≥ 6 不需要「环下落」那种精细控制，
因为构造 F 能精确停位（§12.4）。

### 12.3 算法 2：制造正规核心

```
输入：正规核心 X（每枚晶体接地或正下方非空）
1. 把最高晶体以下的**所有空位临时填成晶体**
2. 暂时去掉底部连续针段 → 剩下紧列 → 用构造 A 制作
3. 顶针补回底部连续针段
4. 从上到下，用构造 D 逐段打碎临时填入的晶体
最后保留一根覆盖目标高度的普通柱。
```

「从上到下」与「逐段打碎」这两条与 n = 4 相同（§5 规则三、§4.9 的实测结论）。

### 12.4 构造 F：至少六象限的受控下落

```
目标第 s 层为普通格，要降到第 d 层：要求 2 ≤ d < s ≤ H，且第 d … s−1 层全空。

沿环用四个连续位置：  针槽柱 N | 目标 A | 辅助柱 B | 碎晶桥柱 E
其余象限为空。三根辅助柱从地面做到足够高度：

    N   第 d−1 层为针，其他层普通     ← 落点的「底部」
    B   第 s−1 层（含）以下某层为晶体，其他层普通
    E   第 k 层为晶体（k 为挑中的刀口层），其他层普通

施工顺序：
  1. 保留目标的原普通柱，接入 B、E
  2. 由 B 接管目标的支撑，把原柱换成 N
  3. 选一条半破轴，保留 N、A、B，去掉 E（至少六象限的半边容得下这三列）
  4. 切口打碎 B 中的晶体通道；第 s 层的目标普通格与 B 的普通格粘成双格，一起下降
  5. B 的第 d−1 层仍在，故双格停在第 d 层；若 d = 1，由地面挡住
  6. 交接回普通柱，清除其他辅助材料
```

**关键性质**：**落点由 B 提供支撑**，因此即使目标的第 d−1 层为空，也能停在第 d 层。
这正是 n = 4 缺的能力（n = 4 的半边只放得下两列，塞不进 N|A|B 三列），
所以 n = 4 才需要算法 4/5/6 那套特化。

补充：选中普通格上方若紧接**连续针链**，这段针跟随下降；其余目标材料保持原位。

### 12.5 算法 3：完整施工（n ≥ 6 的总流程）

```
1. 没有晶体 → 用构造 C 逐层追加目标材料，结束
2. 有晶体 → 运行算法 1、2，做出正规核心
3. 接回最高晶体以上的无晶体尾部（构造 C 逐层追加）
4. **按提升记录的逆序**，使用构造 F，把普通格送回原层
```

论文的示例（`T.c` 的规划）：

```
层   目标    提高普通格后    填临时晶体后
3    c       c              c
2    .       T              T
1    T       .              c ← 临时
```

先做右边（带柱打碎底晶体），再把中间的普通格下降一层，即得目标。

### 12.6 与 n = 4 的分工总表

| | n = 4 | n ≥ 6 |
|---|---|---|
| S 判据 | 五项 ∧ (D∨F) | 五项 |
| 提升 | 算法 6 底块提升 / 算法 4 递归提升，需防「多掉一层」 | 算法 1 单格提升，落点交给构造 F |
| 恢复 | 构造 E 弱下落 / 构造 G 环下落 / 构造 D 碎晶 | **构造 F 受控下落**（落点由 B 支撑，d−1 层可空） |
| 分档 | 5 / 6 / 4 三条特化路线 | 统一 1 → 2 → 3 |

**结论**：n ≥ 6 的算法比 n = 4 **更统一**——没有 D/F 分档、没有「多掉一层」的坑，
因为构造 F 提供了任意层数的受控下落。

### 12.7 现状

- **判据侧**：n ≥ 6 的正确判据（只用五项）尚未在代码里分派（§12.1）；
- **构造侧**：算法 1/2/3 与构造 F 尚未实现，也没有实测样例；
- 实现顺序建议：先做 §12.2 + §12.3（与 n = 4 的算法 2 高度重合），再做 §12.4 的构造 F，
  最后接 §12.5 的逆序恢复。

## 14. 孤立列与二象限可分（定理 4、算法 7、定理 5）

### 14.1 定理 4：孤立列的完整判据

**孤立列** = 成品只保留这一列，不保留任何托柱。
对**任意偶数宽度**，一个孤立列可制作，当且仅当：

```
1. 非空格从地面起连续排列（没有洞）；
2. 晶体以下的针，全部属于底部连续针段。
空列也允许。
```

含晶体时，结构依次是：

```
地面 → 连续 P 段（可为空） → 连续 T/c 核心（以最高 c 结束） → 连续 T/P 尾部（可为空） → 顶部空
```

没有晶体时，任意连续接地的 `T`/`P` 列都可以。

**实测（`IsolatedColumn.IsIsolatedColumn`，与论文例子一致）**：

| 列 | 孤立列 | 五项 | 论文结论 |
|---|---|---|---|
| `PPTTcPT` | ✔ | ✔ | 通过 |
| `T.c` | ✘ | ✔ | 因洞而失败 |
| `TPc` | ✘ | ✘ | 因晶体以下有非底部针而失败 |
| `PPTc` | ✔ | ✔ | 通过（二象限例子的左列） |
| `PTcT` | ✔ | ✔ | 通过（右列） |
| `TT` | ✔ | ✔ | 通过 |
| `.T` | ✘ | ✔ | 反例：失去左列支撑会下落 |
| `.c` | ✘ | ✘ | 洞 + 晶体下无材料 |

**注意**：定理 4 比五项条件**更严**。`T.c` 五项 ✔ 却不是孤立列；
`TC` 类有洞的列只能在“带托柱”的形态下成立（即角工序的 S 形态）。

### 14.2 算法 7：孤立列施工

```
1. 暂时拿掉最高晶体以上的尾部和底部连续针段
2. 用构造 A 做剩余的紧列
3. 顶针补回底部针段
4. 逐格堆叠普通或单针，接回尾部
```

无晶体时直接用构造 B。**成品只保留目标列**（没有托柱、没有桥柱）。
整套施工只用构造 A / B / C，不需要 D / E / F / G——因为没有洞需要造。

### 14.3 定理 5：二象限可分性

二象限时每个半边只有一列，于是：

```
整图可分  ⟺  左右两列都通过定理 4
```

通过后分别制作两列，送入交换机拼合；**空侧用非空普通辅助件的空半边提供**。

论文例子（4 层，左 `PPTc`、右 `PTcT`）：

```
层 4   c   T
层 3   T   c
层 2   P   T
层 1   P   P
```

做法：先制造「普通在下、晶体在上」的孤立两层列——一份顶针两次作左侧；
另一份旋转后顶针一次、再堆普通格作右侧；最后交换。

反例：底层 `T.`、顶层 `TT`（左列 `TT`、右列 `.T`）。整图还能直接堆叠得到，
但右列 `.T` 在失去左列支撑后会下落 ⇒ 属于「**可制作、但不可分**」。

### 14.4 与角工序的关系

| | 角（S 形态） | 孤立列 |
|---|---|---|
| 产物 | 目标列 + 一根托柱 | 只有目标列 |
| 判据 | 五项（n≥6）或 五项 ∧ (D∨F)（n=4） | 定理 4 的两条 |
| 施工 | 需要 D / E / F / G / H | 只用 A / B / C |

**一句话**：角工序做完之后能不能把托柱拆掉，取决于这一列是否满足**定理 4**——
满足就能降到孤立列（更省材料），不满足就必须保留托柱，停在 S 形态。

这条也解释了为什么 §4 的所有配方都保留托柱：它们的产物本来就带洞，不满足定理 4。

## 15. 构造 G：四象限的单孔环下落

### 15.1 用途

**只降一层、且落点下方可以是空的**。这是构造 E（弱下落）做不到的：

```
cT..Tccc → cT.T.ccc      把第 5 层的普通格降到第 4 层，第 3 层仍然为空
   弱下落 → 会一直落到第 3 层
   环下落 → 停在第 4 层 ✔
```

### 15.2 前提（逐条，全部可扫描判定）

记目标列为 `A`，层号 1-based 从地面起；`cap` 为画布高度。

**目标侧**

| # | 条件 | 怎么判 |
|---|---|---|
| G1 | `A` 在区间 `[d+1, s]` 之上有一处**连续晶体段**（至少三颗），设其最下层为 `s` | 从下往上扫晶体段，取段长 ≥ 3 的那段 |
| G2 | 存在空位 `d < s`，使 `(d, s)` 之间**只有普通格和空**（无晶体、无针） | 扫 `d+1 … s−1` |
| G3 | 最终目标第 `d` 层为**空**（原来的空位被搬到 `d`） | 直接看目标列 |
| G4 | 要下降的是 `(d, s)` 之间的**普通材料整体**，只降**一层** | 由 G1–G3 推出 |

**辅助列 B**

| # | 条件 | 说明 |
|---|---|---|
| G5 | B 是**满高连续接地**列（地面到 cap），材料只有普通格 / 一颗晶体 / 一颗针 | 这样才能用「紧列 + 普通格 + 针」独立制造 |
| G6 | B 的**针与晶体相邻**（针在晶体的上一层） | 针不横向粘连 ⇒ 在该处断开横向传递，同时整列仍接地 |
| G7 | B 的**针必须落在环里**：与目标晶体段处在同一层区间 | 环靠 P 把上下两段 T 隔开 |
| G8 | B 的**晶体必须在环的下方**，作为「保险丝」被碎掉 | 碎了它，环下方的支撑断开，材料才降一层 |

**环的几何**

| # | 条件 |
|---|---|
| G9 | 目标与 B **相邻**（四象限里就是隔壁象限），环在 `[s−1, s+1]` 一带闭合：目标侧 `c-c-c`，B 侧 `T-P-T` |
| G10 | 环的两端都要咬合：目标晶体段的上端接 B 的 `T`、下端也接 B 的 `T` |

**切割（桥柱 B′）**

| # | 条件 |
|---|---|
| G11 | B′ 是满高普通列，**仅第 `k` 层为晶体**，`k` = B 的晶体层（同层才连得上） |
| G12 | B′ 必须落在**切割后被丢弃的那一侧**，且与 B 的晶体**横向相邻**（跨刀口） |
| G13 | 刀口穿过 B 与 B′ 的晶体连接 ⇒ B 的晶体整块碎（B′ 的晶体一并带走） |
| G14 | **保留侧必须同时含目标列与 B**（否则切完失去支撑，见 §5 规则四） |

### 15.3 结果不变量（做完必须逐条成立）

1. 只有 `(d, s)` 之间的普通材料**下降一层**；
2. 目标晶体、`≤ d` 的材料、`≥ s` 的环以上材料**保持原位**；
3. 碎掉的只有 `B` 与 `B′` 里的晶体，**目标晶体不受牵连**
   （前提是 B 的保险丝与目标晶体**不属于同一连通块**——见 §5 规则二）；
4. 原来在 `d` 的空位被搬到 `d+1`（等价说：`d` 变空）。

### 15.4 失败模式（每一条都对应一个必须检查的条件）

| 失败 | 原因 | 对应条件 |
|---|---|---|
| 目标晶体被一起碎掉 | 保险丝与目标晶体连成一块 | G8 的反面 / §5 规则二 |
| 材料整体落地 | 切完保留侧没有 B | G14 |
| 什么都没掉 | 刀口没穿过 B 的晶体（层号不齐） | G11 / G13 |
| 掉了不止一层 | 环没闭合，退化成弱下落 | G9 / G10 |
| 环本身塌了 | B 的针不在环里 | G7 |
| 降完之后 `d` 仍非空 | `d` 选错（`(d,s)` 之间有材料） | G2 / G3 |

### 15.5 适用面与边界

- **象限数**：四象限即可（需要一格放 B、一格放 B′）；n ≥ 6 时同样可用，
  且构造 F 覆盖同类需求（F 更通用，G 更轻）。
- **对目标列的额外要求**：只要 `[d+1, s]` 上方有 ≥3 的连续晶体段。
  没有三连晶时构造 G 不适用 ⇒ 退回构造 E（弱下落）或算法 6/4 的其它手段。
- **与构造 E 的分工**：见 §15.6。

### 15.6 单格特例

若三连晶下方只有**最高的一枚**普通格需要移动，且它与三连晶之间全空，
可以把「它正下方的空位」反复当作 `d`，**每次下降一层**，直到指定位置。

### 15.7 与构造 E 的分工

| | 构造 E（弱下落） | 构造 G（单孔环下落） |
|---|---|---|
| 降到哪 | 同列最近的**下方材料**之上（可能多降） | **恰好一层**（`d` 由环锁定） |
| 落点下方为空 | 不行（会继续落） | **可以** |
| 代价 | 托柱一层放针 | 需要 B 列（晶体+针）+ 桥柱 + 一刀 |
| 前提 | 无 | G1–G14 |

**这正是 §4.8 那个 14 层例子卡住的地方**：L9、L10 同属一个晶体块，删掉后 T 下方两格全空，
弱下落的语义会落到 L9，而目标要求停在 L10——只有构造 G 能锁住。

### 15.9 实测实例（8 层，n = 4，已通过）

目标 `cT.T.ccc`（正文 §4.7/§4.9 里那种「精确降一层」的形态）。
D ✘（最低晶体下方 0 个空）、F ✔（三连晶）⇒ 算法 4 的**环下落**分支。

**规划**（论文的 `cT..Tccc → cT.T.ccc`）：

```
① 提升：T@4 → T@5                    （记入恢复表）
② 正规核心：L3、L4 填临时晶体          → col0 = cTccTccc
③ 环下落：装 B + 保险丝柱，半破        → col0 = cT.T.ccc  ✔
```

**实测前态**（四列全部合法、整体稳定）：

```
crCuCuCu:CuCuCuCu:crCuCuCu:cr--Cucr:CuCuCu--:crCuCu--:crP-Cu--:crCuCu--

L8  c  T  T  .
L7  c  P  T  .      ← col1 的针在【环里】
L6  c  T  T  .
L5  T  T  T  .
L4  c  .  T  c      ← col3 的晶体 = 保险丝；col1 在 L4 留空
L3  c  T  T  T
L2  T  T  T  T
L1  c  T  T  T

col0 = cTccTccc   目标列（临时晶体在 L3、L4，T 被提到 L5）
col1 = TTT.TTPT   B（环伙伴：L6=T / L7=P / L8=T）
col2 = TTTTTTTT   满高普通柱（隔开刀口）
col3 = TTTc....   保险丝柱（L4 放晶体，跨刀口与 col0 的 L4 临时晶体相连）
```

**半破（一刀）→ west col0 = `cT.T.ccc` ✔**

这一刀同时做到三件事：

1. `{L3, L4}` 两颗临时晶体（纵向相邻 ⇒ 同一连通块）被整块碎掉；
2. 碎晶经由 **col3 的 L4 晶体**（跨刀口）达成——保险丝在环**下方**，与目标晶体段不连通；
3. T@5 落到 L4 就停住（**下方 L3 是空的**），这就是环的作用。

### 15.10 由实例修正的两条描述

- **G5 修正**：B **不必是满高连续列**。实例里的 B（col1）在 L4 留了个洞，
  只要它的材料在环区间构成 `T-P-T`、并且整图仍然稳定即可。
  「满高」是充分条件，不是必要条件。
- **G8 修正**：保险丝（col3 的晶体）必须位于环**下方**、且**与目标晶体段不连通**；
  它可以放在④「刀口另一侧」的单独一列里，不必长在 B 上。

### 15.11 一个必须澄清的误解：环里用的是普通格，不是晶体

**「B 的晶体要跟目标的三连晶相连」是误读。** 论文画的环是：

```
目标    B
 c      T     ← 普通格
 c      P     ← 针
 c      T     ← 普通格
```

- **环里 B 提供的是 `T-P-T`（普通格 + 针）**，与目标晶体是「形状-晶体」相邻，
  不是「晶体-晶体」相连；
- **B 唯一的晶体在环的下方**（针以下），当保险丝；
- 那一层在目标列里**必然不是晶体**——因为 `(d, s)` 之间按 G2 只有普通格和空，
  保险丝就落在这个窗口里。

所以**碎晶永远不会碰到目标的原生晶体**：

```
碎的是：{目标列的临时晶体} ∪ {保险丝}
碰不到：目标列的原生晶体（第 s 层以上）
```

**「换支撑柱」为什么安全**：构造 G 第 5 步（换回普通柱）发生在碎晶**之后**——
那时保险丝与临时晶体都已经没了，换成普通柱不涉及任何晶体，
目标原生晶体从头到尾没有和任何辅助晶体同属一个连通块。

**反过来说**：如果真让保险丝与目标原生晶体同层相连，碎它必然连带毁掉目标晶体——
这正是 §5 规则二描述的那个坑（`T.T.c` 的两刀模拟就毁在这一点上）。
所以实现时要显式加一条检查：

> **G8a**：B（或独立保险丝柱）的晶体所在层 `k`，目标列在该层**不能是晶体**；
> 且该晶体不得与任何「要保留的晶体」连通。

### 15.12 与构造 H 的区别（容易混）

| | 构造 G | 构造 H |
|---|---|---|
| B 的晶体 | **不与**目标晶体同层相连（在环下方当保险丝） | **晶体桥柱**：晶体按 `z+1 ∈ I` 逐层放，**会**连到目标列的**临时晶体段** |
| 连的是什么 | 目标列的原生晶体（通过环，形状相邻） | 目标列的**临时**晶体（晶体-晶体，故意连） |
| 目的 | 锁定「精确降一层」 | 一次顶针批量下降 |

两者都只碰「临时的东西」，不碰原生晶体——区别只是 G 用环、H 用顶针。
