# 角工序「更优」的评价指标

> 2026-11-17。用于比较同一目标角的多条工序路线。
> **正确性是准入门槛，不参与比较**：任何一条没通过验收的路线直接淘汰。

---

## 0. 准入门槛（Gate）

```
G1 初始前态满足 P1（每颗晶体坐在普通格上）
G2 前态四列过五项、整体稳定
G3 每一步与真实物理逐格一致
G4 最终列逐格等于目标
```

四条全过才进入下面的比较。

---

## 1. 指标一览（按优先级排序）

| 序 | 指标 | 定义 | 计数方式 | 为什么排这个位置 |
|---|---|---|---|---|
| **M1** | **弱落次数** | `WeakDrop` 步的数量 | 数 Kind | 弱落要「撤原柱 → 落到某层 → 装回柱」，最容易出错，也最难读；**能省就省** |
| **M2** | **顶针次数** | `Pin` 步的数量 | 数 Kind | 每次顶针都要换一轮辅助列；且顶针次数多通常意味着底针多（那是目标本身要求，可辩解） |
| **M3** | **半破次数** | `Cut` 步的数量 | 数 Kind | 每刀都要重装桥柱/保险丝；≥3 刀说明分刀策略没优化 |
| **M4** | **辅助列根数** | 前态里非空的辅助象限数 | 数 col1..col3 | 2 根（碎晶）< 3 根（顶针）；影响材料与摆放 |
| **M5** | **换柱次数** | `Support` 步的数量 | 数 Kind | 换柱是纯机械劳动，不改变目标列 |
| **M6** | **总步数** | `Steps.Count` | 数数 | 影响可读性；但只在前五项打平时才看 |
| **M7** | **材料消耗** | 前态四列的总格数（不含空） | 数 `T/c/P` | 影响建造量；同分时取小 |

**比较规则**：按 M1 → M7 依次比较，先小者优（**字典序**）。
不要用加权求和——弱落多一次和一个辅助列，重要性差一个量级。

---

## 2. 两个「不可比」的情形

### 2.1 目标本身要求（不算退化）

- **底针 m 枚** ⇒ 至少 m−1 次换针是**目标要求的**，不算路线差；
- **必须多次弱落才做得出**的角（用户指出确实存在）⇒ 那几次弱落是**下界**，不算路线差。

**判据**：如果一条路线的弱落次数等于该角的下界，它就是最优，不再比较。

### 2.2 不同构造不可直接比

构造 H（顶针）与构造 G/D（碎晶）是两种机械，M4/M7 天然不同。
比较时**先按构造分组**，只在同组内选优；跨组比较以 M1 优先（弱落少者胜）。

## 4. 怎么用这些指标做回归

```
对每条新路线：
  ① 跑 Gate 四条
  ② 记录 (M1..M7)
  ③ 与该角的旧路线逐项比较（字典序）
  ④ 若新路线在某项变差，必须说明原因（例如「换来少一次弱落」）
```

**回归门槛**（防止为了指标把覆盖率做坏）：

```
3–9 层全部 S 列失败数必须仍为 0
```

## 5. 反例：什么样的「优化」不算优化

| 做法 | 为什么不算 |
|---|---|
| 把弱落拆成两个 `Collapse` 步来「减少弱落计数」 | 指标被规避，实际更差 |
| 把 3 根辅助列压成 2 根但要多一次顶针 | M1/M2 优先于 M4，属于变差 |
| 用一个长前态把弱落吃掉，但前态 12 层 | M7 变差，但 M1 变好 ⇒ **算优化**（M1 权重最高） |
| 减少步数但引入「未验证」的前态 | Gate 不过，直接淘汰 |
