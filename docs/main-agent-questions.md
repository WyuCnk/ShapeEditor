# 主智能体的疑问（构造 H 的通用性）

> 2026-11-15。**本文只提疑问，未改任何代码。**
> 背景：`T..cT.T.c`、`T.T.cccTc` 两个 9 层缺口，目前是用 `TryBuildConstructedHLifted`
> （底块整体抬一格 + 晶体整体下移一格 + 普通格两种确定性落位形态）修好的。
> 用户指出这套写法**不通用**，需要先把规则整理清楚。

## Q1 核心规则：普通格必须抬到**晶体正下方**，这条是不是无条件的？

用户的表述：

> 这种晶下间隙，都是得把普通形状抬升到晶体的正下方吧？不管是半破碎晶还是顶针碎晶，
> 这一条都是必须的，本质就是为了让**用来制造间隙的晶体不破坏原生晶体**。

我的理解（请确认）：造洞时若临时晶体紧贴原生晶体，碎晶会把原生晶体一起带走
（§5 规则二）。所以「普通格垫在晶体与临时晶体之间」是**防连炸的必要条件**，
与用 `Cut` 还是 `Pin` 无关。

**疑问**：

1. 这条是否对所有构造（D/G/H）都成立？
2. 如果目标本身**没有**可抬升的普通格（例如 `.T...c` 这种洞比普通格多），
   是不是就说明该角**不可制作**（或只能保留晶下间隙）？§19.3 给的结论是
   「`.T..T..c` 的晶下间隙不可避免」——那与这条规则冲突吗？

## Q2 「整体下移一格」是顶针的倒推，那它和「底块提升」是什么关系？

用户的表述：

> 至于整体下移一格，本质是顶针碎晶的倒推，反推出顶针前的图形。

我的理解：构造 H 的前态 `A` 是「顶针后 = 目标」的**反解**——把目标整体下移一格，
再补齐需要被碎掉的临时晶体。

**疑问**：

1. 「整体下移一格」适用于**所有**顶针路线，还是只适用于「底块提升之后」的形态？
2. `A` 的第 1 层为空，是**下移的必然结果**（下移后顶部空出），还是一条**独立前提**
   （避免 Pin 在第 1 层补针）？
3. 若目标底层是 `T`（如 `T..cT.T.c`），下移会把 `T` 移到第 0 层吗？还是必须
   先底块提升、让第 1 层空出来？这两种理解会导出不同的前态。

我目前用「两种确定性落位形态」（统一 `t−1` / 晶体下方保留原位）绕过去，这是**猜的**。

## Q5 与 §5.3「先剥尾、后接尾」的先后关系

- §5.3 说 `Hc` = 整图最高晶体层，剥掉 Hc 以上的尾部后再进角工序；
- 构造 H 要求 `A` 第 1 层为空（Pin 不补针）；
- 底块提升要把最底两层清空。

三者都改 `A` 的形状，**谁先谁后**？现在的实现是「底块提升 → H」，但塔式路线
曾出现「A 过了前置检查、Pin 时 B 柱把 T 拖走」的情况（`T..cT.T.c` 修复前的现象）。

**疑问**：是否需要一条**联合校验**（前态合法性 + 一次真实 Pin 的预演）来替代分散的前置检查？
