## 二、已确定的领域规则（不要重新发明）

### 2.1 图形表示

- 竖式图：层（从下往上，第 0 层在最底）× 象限（环形排列）。
- 象限编号：**1 = 东北象限**（中轴线右上方），之后顺时针 2、3、4……
- 象限数必须为偶数，范围 2–100；层数 1–100，单元格总数上限 10000。
- 短代码：`:` 分层，每两个字符一象限（形状 + 颜色）；超短代码：每位一象限（`C` 普通形状、`c` 晶体、`P` 顶针、`-` 空位）。

### 2.2 下落规则（两种）

- `IncludeCycles`（含循环支撑）：互相支撑的环可以悬空。
- `FloorOnly`（仅地面）：必须有来自底部/相邻的支撑。

### 2.3 角与角合法性

**角 = 竖式图的一列。** 一个角合法当且仅当：

1. 顶针下方相邻格必须非空；顶针在最底层视为合法。
2. 晶体下方若存在顶针，该顶针要么在最底层，要么其下方全部是顶针。
3. 同列两层晶体之间若存在空层，则两者之间至少有两个非空格，且**下方晶体**的正上方非空。
4. 最低的那层晶体：在最底层、或下方存在普通形状、或下方全部是顶针。

### 2.4 稳定性

- 对图形执行一次下落，若结果与原来逐格相同，则稳定。
- 稳定性与下落规则相关（同一图形在两种规则下结论可能不同）。

### 2.5 半边稳定性与交换方向

- 轴：把环形象限沿某条中线切成两个连续半边，共 `n/2` 个轴。
- 半边图形：保持原象限数，只保留该半的列，其余列清空（**投影，不是切割**）。
- 带柱子的半半边：给半边左右各补一列满层 `Cu` 柱子（柱子补到原图总层数），再按内部切点二分，得到两个"带柱子的半半边"（各含至少一个柱子）。
- **交换方向** = 轴 × 左切点 × 右切点，共 `n/2 × (n/2−1)²` 个。
- 某方向合法 ⇔ 两个半边稳定，且该方向上左右各两个带柱子半半边全部稳定。
- 只要存在一个合法方向，称图形「可交换」。

### 2.6 交换操作

两个输入 → 各切割一次 → 得到 `A东/A西`、`B东/B西` → 交叉拼接：

```
输出1 = A东 + B西
输出2 = A西 + B东
```

（东/西与"左/右"的对应沿用现有实现；结果取哪一个由后续工序决定。）

### 2.7 旋转

- 顺转一个象限、逆转一个象限、反转（顺转 `n/2` 个象限，即对角）。
- 象限编号 1=东北、顺时针递增，所以顺转 = 编辑区「右移」。

### 2.8 结晶

输入颜色代码（如 `r`），把图形中**所有空位与顶针**替换成该颜色的晶体。

### 2.9 图形性质（已实现）

包含晶体 / 包含顶针 / 晶空同层 / 晶顶同层 / 图下间隙 / 晶下间隙 / 同层异色晶体 / 循环支撑结构 / 稳定 / 可交换。

- **图下间隙**：某空位，正上方是普通形状，且更上方存在晶体。
- **晶下间隙**：某空位，正上方是晶体。
- **循环支撑结构**：含循环支撑规则下的下落结果与仅地面规则不同。

### 2.10 可制作性

- 存在不合法角 ⇒ 不可制作。
- 但「全合法」不等于可制作，必须以制作路径解析成功为准。
- 角的可制作性 = 给该角相邻象限补一列满层 `Cu` 后图形可制作（角落算法后续补，暂时等同角合法）。

## 三、制作路径的工序链（待定稿）

```
（完整版才显示）制作 4 个带柱子的半半边
        ↓ 交换（同侧两两配对，舍弃废料柱子）
      得到 2 个半边
        ↓ 交换（舍弃废料）
      得到目标图形
        ↓ 若干次顶针 / 堆叠（顺序待定）
```

- 简约版隐藏第一步，完整版显示。
- 交换的判定：两个输出中**任意一个**等于期望图形即成功，另一个视为废料。
- 顶针与堆叠的位置、顺序尚未确定，是待设计重点。

### 已确认的样例（6 象限）

目标 `123456`，方向 `(12+3)+(4+56)`：

```
四个带柱子的半半边：C12000、0003C0、0C4000、00056C   （C=满层 Cu 柱子，0=空）
C12000 + 0003C0 = C123C0 + 000000（废）
0C4000 + 00056C = 0C456C + 000000（废）
C123C0 旋转 → 123C0C
0C456C 旋转 → C0C456
123C0C + C0C456 = 123456 + C0CC0C（废）
```

注意样例里**交换之后有旋转**，旋转规则尚未明确。

## 四、你要产出的东西

1. **算法规格（可以先用阉割版）**：输入（图形 + 下落规则）→ 输出（是否存在路径 / 路径步骤列表）。
2. **每一步的精确输入输出**：所用操作（交换 / 旋转 / 结晶 / 顶针 / 堆叠）、参数、中间结果怎么算。
3. **成功判据**：与目标"完全一致"还是"包含"；废料如何判定与丢弃。
4. **搜索顺序与复杂度**：方向遍历顺序、剪枝条件、`n=20` 时的量级估算。
5. **可直接写成测试的样例**：至少 3 个「确定可制作」+ 2 个「确定不可制作」的短代码图形，以及期望路径。
6. **数据结构的形状**：供 UI 画出节点链（步骤名、图形快照、连线关系）。
