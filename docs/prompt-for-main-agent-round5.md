# 给主智能体的提示词（第五轮：O-v2，碎晶为主、多刀优先于弱落）

> 把下面整段发给主智能体。

---

## 本轮目标

把路线主角从**顶针（构造 H）**换成**碎晶（构造 D/G）**，
并把「多刀 + 交换支撑柱」提升为独立一档，排在算法 6 的弱落之前。

当前 3–9 层虽已零失败，但路线选择不最优：`T.T.T.c` 走的是算法 6 + 2 次弱落，
而它其实应当走「多次切割」。

必读：

1. **`docs/angle-route-optimal-v2.md`**（O-v2 规格，尤其 §2 碎晶规格、§7.1 优先级）
2. `docs/work-order-metrics.md`（M1–M7 指标）
3. `docs/angle-work-order-general-algorithm.md` §0.12（三条约定：统一收尾 / 换柱五步 / 能抬多高抬多高）

---

## 一、路线优先级（**以本节为准**）

```
① 碎晶·一刀            M1 弱落=0，M3 刀=1     ← 最优
② 碎晶·多刀 + 交换支撑柱  M1 弱落=0，M3 刀=2~3   ← 次优
③ 顶针（构造 H）        M1=0，M4 辅助列=3
④ 算法 6 四步（含弱落）  M1 ≥ 2               ← 最差
```

**判据：M1（弱落次数）权重最高。多刀虽然 M3 更差，但 M1 是 0，总体优于算法 6。**

---

## 二、碎晶·一刀的规格

```
A（第 1 象限）= 目标列把「最高晶体以下」的所有空位填成临时晶体 ⇒ 紧列，c/T 交替
S（第 2 象限）= 满高普通格，在被提升格的【落点层】放针
第 3 象限   = 空
F（第 4 象限）= 满高普通格，在每个【临时晶体段的锚层（最上层）】放一颗晶体
一刀 → 临时段整段碎 → 被提升的普通格落回目标层
收尾 → 构造 C；Target = 左柱 + 目标列 + 右柱
```

**四个回归基线（必须逐格通过）**：

| 目标 | A | S | F | 刀数 |
|---|---|---|---|---|
| `T.c` | `cTc` | `TPT` | `c..` | 1 |
| `T...c` | `cccTc` | `TTTPT` | `TTc` | 1 |
| `.TT.cTT.c` | `cTcTcTcTc` | `TTTPTTTPT` | `cTcTTTc..` | 1 |
| `T.T.c`（第一刀后） | `cTcTc` | `TTTPT` | `TTc..` | 1 |

> `.TT.cTT.c` 有**两段不连续的临时晶体**（`{2,3}` 与 `{7}`），保险丝在两段各放晶体，一刀碎两段。

---

## 三、碎晶·多刀的规格

`T.T.c` 与 `T.T.T.c` **没有一刀解**，必须多刀。`T.T.c` 的完整序列（用户给出）：

```
第 1 刀：crCu--Cu:CuCu--Cu:crCu--cr:CuP-----:crCu----   → cTT.c
换柱① ：crCu--Cu:CuCu--P-:CuCu--Cu:--P---Cu:crCu--Cu
旋转   ：CucrCu--:P-CuCu--:CuCuCu--:Cu--P---:CucrCu--
换柱② ：Cucrcr--:P-Cu----:CuCu----:Cu------:Cucr----
第 2 刀：CuCu----:P-------:CuCu----:Cu------:Cucr----   → T.T.c
```

**交换支撑柱必须按五步写成具体工序**，每步给出完整四列短代码：

```
① 旋转 R 个象限，让旧支撑柱落到指定象限
② 另一侧装新支撑柱（连续接地，覆盖目标现有高度）
③ 由新柱接管支撑
④ 拆旧柱与旧保险丝柱
⑤ 逆旋转回来
```

**终止条件**：临时晶体块集合 `K` 清空（不是轮数上限）。

---

## 四、收尾形态统一

```
Target = [支撑柱] [目标列] [支撑柱]
```

- 两侧柱覆盖目标现有高度；
- **消除手性**（不用判断托柱在左还是右、保留侧是东还是西）；
- 验收：`Target` 的中间列逐格 == 目标；两侧柱连续接地、无洞、过五项。

---

## 五、抬升原则

```
晶下间隙的初始前态：晶体正下方【相邻】必须是普通格（P1）
普通格【能抬多高抬多高】（抬高给它留下降空间，也缩短临时晶体段）
```

---

## 六、指标回归

每列记录 `(M1 弱落, M2 顶针, M3 刀数, M4 辅助列, M5 换柱, M6 步数, M7 材料数)`，
按 M1→M7 字典序比较新旧路线，**新路线不得在 M1 上变差**。

---

## 七、提交前自检

```
1) 3–9 层全部 S 列失败 = 0
2) 五个回归样例逐格通过：T.c / T...c / .TT.cTT.c / T.T.c / T.T.T.c
3) T.T.c 与 T.T.T.c 走「多刀 + 交换支撑柱」，弱落数 = 0
4) 含弱落的列数从 211 降到 < 100
5) Target 统一为「左柱 + 目标列 + 右柱」
6) 换柱工序若出现，必须带完整四列短代码
7) 耗时 ≤ 8 s
8) 规则与代码冲突就直接指出，不要自行取舍
```

---

## 八、完成后回报

```
· 各层失败数（应为 0）
· 路线占比：碎晶一刀 / 碎晶多刀 / 顶针 / 算法6
· 含弱落列数、多刀列数（按层数）
· M1–M7 总体平均（新旧对比）
· 你认为规格不清或与实现冲突的地方
```
