## 二、文档的三处错误（请 Core 修正）

### E-1 §0.3.1 的「`N` 枚数 = 要下降的普通格个数 + 1」与它自己的回归表不符

| 目标 | 要下降的普通格 | 公式给的针数 | 表里的 `N` | 实际针数 |
|---|---|---|---|---|
| `.TT.c` | 2 | 3 | `TPPT.` | **2** |
| `.TTT.c` | 3 | 4 | `TPPPT.` | **3** |

- `.TT.c` 的 2 枚针在 **L2、L3**；
- `.TTT.c` 的 3 枚针在 **L2、L3、L4**。

⇒ 公式多算了一枚。实测通过的规则是：

```
N 的针段 = 第 2 层起连续，一直到 max(I) 那一层
（不是「下降格数 + 1」）
```

**建议**：§0.3.1 的公式改成「针段 = L2 … max(I)」，并说明与 §0.3 的 `J` 口径为什么不同。

### E-2 `BTop` 在文档表内部不自洽

| 目标 | `max(I)` | 最高源层 | 文档给的 `BTop` |
|---|---|---|---|
| `.TT.c` | 3 | 4 | **3** |
| `.TT.Tc` | 3 | 4 | **4** |

两列的 `max(I)` 与「最高源层」完全相同，`BTop` 却差 1。

实测能复现四行表的公式是：

```
BTop = max( max(I), 最高源层 − 1, 最高晶体层 − 2 )
深落差（s − d ≥ 2）时再扩到 max( …, 最高源层, 最高晶体层 − 1 )
```

**建议**：§0.3 与 §0.11.2 ⑧ 的 `BTop` 公式按上式更正，并说明「深落差要额外扩一层」。

### E-3 §0.11.5 的「撤回声明」与实测相反

§0.11.5 写：

> 「`.TT.c` 的『一次顶针』说法已被实测反证（用文档自己的前态 `.TTc.` 回放，得不到 `.TT.c`）」
> 「O 目前只是一个『目标』而非『已验证的算法』」

实测（真实 `ShapePhysics.Pin`，逐格）：

```
A=.TTc.  B=cTT..  E=ccccc  N=TPPT.   →  顶针 → .TT.c  ✔
```

四个回归前态（`.TT.c`、`.T.T.c`、`.TTT.c`、`.TT.Tc`）**全部通过**。

**建议**：§0.11.5 的撤回声明改为「已复核：四个回归前态均可用文档前态一次顶针复现；此前『被反证』的结论是探针实现问题」，并保留「O 的通用推导规则仍不完全（见 §0.3.1）」这一条。
