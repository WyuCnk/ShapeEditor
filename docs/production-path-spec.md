## 0. 记号与模型

### 0.1 图形与层号

- 竖式图：`n` 个象限沿环排列（`n` 为正偶数），层从地面向上。
- **象限索引**：`0` 起，`0` = 东北，顺时针递增（与 `ShapeDocument` 一致）。
- **层号**：本文用论文的 1 起写法，`层号 = ShapeDocument 层索引 + 1`。
- **列字符串**：左端是底层，右端是顶层。

| 符号 | 含义 | `ShapeCell` |
|---|---|---|
| `.` | 空 | `Empty` |
| `P` | 顶针 | `Pin` |
| `T` | 普通实体格 | `Shape`（具体形状与颜色不影响判定） |
| `c` | 晶体格 | `Crystal` |

顶部连续全空的层可以省略；底部和中间的空位必须按原层号保留。

### 0.2 cap（高度上限）

**机器 cap = 画布层数（`ShapeDocument.LayerCount`）**，整条制作路径共用同一个 cap，所有辅助件和中间成品都用它。

cap ≠ 目标可见高度。目标只有 3 层内容但画布是 5 层时，`顶针` 会把内容抬到第 2 层而不是全部截掉——这一点在 4 象限 5 层上实测过，判定和构造都必须显式带 cap。

### 0.3 六个操作

| 操作 | 我们的实现 | 语义要点 |
|---|---|---|
| 旋转 | `MoveLeftCircular` / `MoveRightCircular` | 顺转 = 象限索引 +1 |
| 切割（半破） | `ShapePhysics.Cut` | 沿 `n/2` 切；跨刀口晶体整块碎；**两半各自再塌陷一次** |
| 交换 | `ShapeExchange.Exchange` | 两输入各切一次，`out1 = A东+B西`，`out2 = A西+B东`；合并逐格「左非空取左」 |
| 堆叠 | `ShapePhysics.Stack` | base + 一空层 + top → 塌陷 → 截到 cap |
| 结晶 | （待实现） | 把**所有空位与顶针**替换成指定颜色晶体 |
| 顶针 | `ShapePhysics.Pin` | 内容整体上移一层；底层按原第 1 层非空位补 `P`；截到 cap；塌陷 |

> **顶针的 cap 语义**（已验证）：`Pin` 的上限是**画布层数**。画布 5 层、内容只在第 1 层时，顶针只把内容抬到第 2 层，不会截掉；要截掉必须显式「超上限删除」到更小的 cap。

### 0.4 与论文记号对照

论文的「普通实体格」= 本文 `T` = 我们的 `Shape`（`Cu` 之类）。论文的「半破」= 切割，「交换」= 交换，「结晶」= 结晶，「顶针」= 顶针，「堆叠」= 堆叠。完全一一对应。

## 1. 基础定义

### 1.1 列、晶体段、核心与尾部

- **晶体段**：同列中最大的一段连续晶体（颜色不同也算连续）。
- **核心**：最高晶体及其以下的部分；**尾部**：最高晶体以上的部分。
- **紧列**：从地面连续排列、只含 `T`/`c`、中间没有空位的列。

### 1.2 粘连组与晶体簇

只有以下接触会粘连：
1. 同层相邻的 `T` 或 `c`（两两都能粘连，跨环相邻也算）；
2. 同列上下紧邻的两枚 `c`；
3. **`P` 各自成组，不与任何东西粘连。**

沿这些连接能到达的全部格子组成一个**最大粘连组**（可同时含 `T` 和 `c`）。只沿晶体之间的连接得到的部分称为**晶体簇**。

> 与 `PhysicsGrid` 一致：`ConnectsHorizontally` 只连形状/晶体，`ConnectsVertically` 只连晶体-晶体，顶针是独立组。

### 1.3 一次下落与稳定

1. 按当前网格确定所有最大粘连组；
2. 找一组可以整体下降一层的材料（不穿地、不撞其他组）；
3. **删除该组中的全部晶体**，余下材料下降一层，只在这组余下的材料内部重新分组；
4. 重复，直到没有组能下降。

同一次下落只按第 3 步更新组；原本不同的组即使发生新接触，仍保持各自身份。任意合法顺序结果相同。
**初始就没有组能下降 ⇒ 稳定。** 接地支撑与循环支撑都能保持稳定。

### 1.4 三种制作要求

| 名称 | 成品包含什么 | 记号 |
|---|---|---|
| **孤立列** | 只有目标列，其余所有象限为空 | — |
| **带普通支柱列** | 目标列 + 一根相邻普通柱（从地面连续，至少覆盖目标列高度） | **S** |
| **合法列** | 目标列能出现在某个可制作整图中，其他列允许任意辅助结构 | **L** |

含义：`孤立列 ⊆ S ⊆ L`。第四、六节的列构造都以 **S 为成品**。

### 1.5 半破可得半边与可分形状

- **静态半边**：把另一半涂成空，完整保留留下半边的材料和层号（投影，不是切割）。
- **半破可得半边**：该半边能作为某个**非空可制作输入**的半破输出。
- **可分形状**：存在某个朝向，使纸上分开的两个半边都半破可得。

实际制作时把两个原输入送入交换机，取需要的输出即可。空半边允许；实际机器输入必须非空，空侧由非空辅助件提供。

> 注意：**半破可得 ≠ 半边稳定**（定理 6 会给出精确判据，见 §2.7）。我们现有的
> `HalfStabilityAnalyzer` 要求「半边本身稳定」，那是充分不必要条件。

## 2. 判据【论文，全部任意层、不打表】

### 2.1 五项共用条件（= 我们的角合法性）

**条件 1（针有直接支撑）**：每枚针要么接地，要么同列正下方非空。

**条件 2（晶体以下的针只能在底部连续针段中）**：如果一枚针上方还有晶体，那么从地面到这枚针必须全部为针。
`PPTTc` 允许，`TPc` 不允许。最高晶体以上的尾部针只需满足条件 1。

**条件 3（非最高晶体有上盖）**：如果某枚晶体上方还有另一枚晶体，那么它正上方一格必须非空。
最高晶体上方允许留空，所以 `c.T` 满足。

**条件 4（晶体下洞需要普通资源）**：对每一枚晶体，只要它下方有空，它下方就至少要有一枚 `T`。
统计范围是这枚晶体以下的所有层。`T.c` 通过，`.c` 失败。

**条件 5（晶体之间的洞需要两枚普通资源）**：任意两枚晶体之间只要有空，严格位于它们之间的 `T` 至少有两枚，可以分散。
`cT.T.c` 通过，`cT.c` 失败。

### 2.2 定理 1（共用必要条件）

任意宽度、任意高度的**合法列 L 都满足五项条件**。所以五项中任何一项失败，即可直接判定不属于 L，更不属于 S。

> **与我们的角合法性等价**（已验证）：把 `ShapeAngleAnalyzer` 与五项条件在层数 1–8 上
> 逐层穷举对表，计数**完全相同**：
> `4, 14, 47, 152, 476, 1451, 4328, 12688`。
> 两条"看着不同"的写法等价：
> 我们写「≥2 个非空」，论文写「≥2 个 `T`」——两晶体之间若有 `P`，条件 2 要求该针从地面全为针，
> 与「下方有晶体」矛盾，所以那里只可能是 `T`；
> 我们只查最低晶体，论文查每一枚晶体——多余的晶体若有洞且下方无 `T`，它和下方晶体之间必然 0 个 `T`，
> 条件 5 已经拦掉。

### 2.3 定理 2（n ≥ 6 的判据）

对任意偶数 **W ≥ 6**：

```
u ∈ L  ⟺  u ∈ S  ⟺  P(u)
```

其中 `P(u)` = 五项条件全部通过。也就是说 **n ≥ 6 时「合法列」与「带柱可造列」是同一个集合**，
五项条件既是必要也是充分；不需要 D/F。

> 这正是「象限数越多越平凡」的形式化表述：n = 4 时 L 严格包含 S（`cT.T.c` 就是反例），
> n ≥ 6 时两者重合。原因是半边宽度 ≥ 3 后，内部列保留两个邻列，D/F 那两个补丁不再需要。

### 2.4 定义 D/F 与定理 3（n = 4 的 S 判据）

**定义 D（底部资源条件）**，满足任一项即可：
1. 没有晶体；
2. 最底格为针；
3. 最低晶体以下至少有两个空格（可不相邻）。

**定义 F（递归终点条件）**：检查每个「正下方为空的**晶体段底端**」，必须满足下面一项：
1. **环下落条件**：从这里开始至少三枚连续晶体；
2. **弱下落终点条件**：在它与下方最近晶体之间存在相邻的普通双格 `TT`；
   若下方没有晶体，也允许以**第 1 层的普通格**为终点。

（`TT` 的两格都位于所考察晶体与下方最近晶体之间；三连晶从所考察段底开始连续向上排列。）

**定理 3**：

```
n = 4 时   列可造为 S  ⟺  五项条件  ∧  ( D ∨ F )
```

手工判定顺序：
1. 检查五项，失败则拒绝；
2. 检查 D，成立则接受；
3. 对每个晶体下洞检查 F，有一处失败就拒绝，否则接受。

判据适用于任意正高度上限。

| 目标列 | S 判定 | 原因 |
|---|---|---|
| `cT.T.c` | 否 | 短晶体下有洞，区间内没有相邻 `TT` |
| `cTT..T.c` | 是 | 短晶体下有普通双格终点 |
| `cT.T.ccc` | 是 | 三连晶允许环下落 |
| `cT.T.cccPT` | 是 | 晶体核心可做，最后追加 `PT` 尾部 |
| `.T..T.c` | 是 | 最低晶体下至少两空 |

> `cT.T.c` 正是中文短代码里的 `cS-S-c`（S=`T`）。**它是合法列 L，但不是 n=4 的 S。**
> TMAM 那张 19 状态角 DFA 数的就是这个 S 语言：按 `五项 ∧ (D∨F)` 实现后，
> 层数 1–7 的计数与它逐位吻合（`4,14,47,152,476,1450,4320`），
> 8 层差 1 个（我们的 F 边界实现尚有一处未对齐，待查）。

### 2.5 定理 4（孤立列判据，任意偶数宽度）

一个孤立列可制作，当且仅当：
1. 非空格从地面起连续排列；
2. 晶体以下的针全部属于底部连续针段。

空列也允许。含晶体时结构依次为：

```
地面 → 连续 P 段 → 连续 T/c 核心 → 连续 T/P 尾部 → 顶部空
         可为空       以最高 c 结束        可为空
```

没有晶体时，任意连续接地的 `T`/`P` 列都可以。

`PPTTcPT` 通过；`T.c` 因洞失败；`TPc` 因晶体以下有非底部针失败。

### 2.6 定理 5（n = 2 可分性）

n=2 时每个半边只有一列，因此：

```
整图可分  ⟺  左右两列都通过定理 4（孤立列判据）
```

通过后分别制作两列，送入交换机拼合；空侧用非空普通辅助件的空半边提供。

> 反例：底层 `T.`、顶层 `TT` 可制作但**不可分**——右列 `.T` 会在失去左列支撑后下落。

### 2.7 定理 6 + 算法 8（n = 4 的半边可获取性）

**定理 6**：一个四象限半边 Q 半破可得，当且仅当**存在两根 S 列**，使它们**不带外柱、直接拼合后的一次完整下落恰好得到 Q**。

下落前的两列称为**前态**。前态由算法 8 确定：

**第一候选：Q 本身**
1. 用定理 3 判断 Q 的两列是否都属于 S；
2. 判断 Q 是否稳定（一次下落后仍等于 Q）；
3. 都通过 ⇒ 采用 Q 作为前态，结束。

**第二候选：联合逆提升**（第一候选失败时）
1. 找两列各自最高的晶体；若有一列没有晶体、或两枚最高晶体**等高**，拒绝本分支；
2. 选两枚中**较低**的那枚，按 §1.2 找与它粘连的全部材料，组成最大粘连组 G；
3. 令 `b` = G 的最低层；在 `b` 以下找**最高的非空层** `h`（任一列有材料就算）；
4. 要求这一层存在，且：第 `h` 层两列都是 `T`（组成水平 `TT`）、`h < b-1`、第 `b-1` 层两列都为空；
5. 把这一对 `T` 从第 `h` 层一起**提高到第 `b-1` 层**，其他格子不动，得到候选前态 Q′；
6. 检查 Q′ 的两列都属于 S，并按 §1.3 手算一次下落；结果恰好是 Q 则接受，否则拒绝。

任一候选通过 ⇒ 半边可得；两个候选都失败 ⇒ 半边不可得。

> 例：左列 `cT.T.cT.Tccc` 不在 S，却能作为半边出现——把第 4 层的 `TT` 提到第 5 层即为前态。

### 2.8 算法 10（n = 4 可分性）

1. 尝试目标的两条分割轴；
2. 对每条轴，静态取出左右两半，分别执行算法 8；
3. 只要某条轴的两个半边都通过 ⇒ 整图可分；两条轴都失败 ⇒ 不可分。

配方：按算法 9 先准备两个半边各自的带外框输入，然后直接交换。右半可以先旋转半圈，按与左半相同的方式分析和制作，最后再转回。

### 2.9 判据速查

| 问题 | 完整判据 | 适用范围 |
|---|---|---|
| 合法列 L（角） | 五项条件（必要） | 任意偶数宽度、任意层 |
| 带柱列 S | 五项条件 | n ≥ 6 |
| 带柱列 S | 五项 ∧ (D∨F) | n = 4 |
| 孤立列 | 连续接地 + 晶体以下针前缀 | 任意偶数宽度 |
| n = 2 可分形状 | 两列分别通过孤立列判据 | n = 2 |
| n = 4 可分形状 | 某条轴的两个半边分别通过算法 8 | n = 4 |

四象限一般 L 的直接列判据只覆盖：cap ≤ 6 时五项条件也是 L 的完整判据；任意高度下对满足 D 的列 L = S。其余情形要把邻列一起画出，用算法 8 判。

## 3. 构造库 A–H

> 每个构造给出「目的 / 前置 / 步骤 / 用到的操作」。层号用论文的 1 起写法。
> 论文里 F/G/H 的层号是行内公式，`pdftotext` 抽不到；已用 `pdftoppm` 把第 5–7 页渲染成图逐页核对，
> 下面三个构造的层号与集合全部按原文录入。

### 构造 A：连续普通／晶体列（紧列）

**目的**：造一条从地面连续、只含 `T`/`c` 的列，外面套一圈普通外框。
1. 准备一个**单层普通件**，只有目标象限为空，其余象限全是 `T`；
2. 第 1 层直接取这个件；以后把它**堆叠**到已完成的各层之上；
3. 若本层需要普通格，在目标象限堆入所需的普通单格；
4. 若本层需要晶体，**按颜色结晶**——此前的层已经填满、当前层只缺目标格，所以结晶只在该缺口生成晶体；
5. 重复到顶，再用**旋转 + 半破**保留目标列。

拆除普通外框后目标晶体簇完整、连续接地的目标列保持原位。两次适当朝向的半破可以只保留指定象限。
造较宽的紧辅助件时：先做各条紧列，再交换组装——每列都连续接地，组装时不会掉落。

### 构造 B：单顶针与连续的普通／针列

**目的**：造一枚顶针（任意 cap）。
1. 从**满一层普通原料**开始，顶针 `k` 次，得到满高的针图；
2. 结晶，得到满高的纯晶体图；
3. 再顶针一次：晶体超限引发**整簇破碎**，只留下最底层的针；
4. 旋转、半破，只保留所需象限的一枚针。

普通单格与单顶针可以逐格堆叠，制造任意连续接地的 `T`/`P` 列。

> 这与我们之前的「单层画布顶针」是两条路，这条对任意 cap 都成立。

### 构造 C：支柱交接与追加材料

**换支柱**：先装新支柱，再拆旧支柱。
四象限例（目标在第 1 列，旧柱在第 4 列）：先交换接入第 2 列的新柱；再换轴保留第 1、2 列，去掉旧柱。两根柱都必须覆盖目标现有高度。

**追加无晶体尾部**（自下而上逐层）：
- **要留空**：单独增加支柱高度；
- **要加普通格**：先让支柱顶端位于新层正下方，再堆叠横跨目标与支柱的普通双格，它会停在新层；
- **要加针**：在目标现有顶格上堆叠单顶针，再补齐支柱（针的下方必须非空）。
- 第 1 层若需要材料：直接取普通单格或制作单顶针，再与支柱拼合；空目标列只需保留支柱。

### 构造 D：定向碎掉一个晶体段

**目的**：只炸掉目标列里选定的那一个晶体段，其余段完好。
1. 在目标**另一侧**装一根连续接地的辅助列，**仅第 k 层为晶体**，其余都是 `T`；
2. 调整切割方向，保留目标和原普通柱，删去辅助列；
3. 切线穿过第 k 层的晶体连接，使选中的目标晶体段**整段破碎**。

其他晶体段由空、普通格或针与该段隔开，不随之破碎。被删段上方若紧接连续针链，只有这段针链要向下落到新支撑上。

### 构造 E：弱下落

**目的**：让目标列第 **s** 层的一枚普通格落到**同列最近的下方材料之上**或地面。
1. 在目标另一侧装一根连续接地的辅助列，**仅第 s 层为针**，其他层为 `T`；
2. 去掉原普通柱，只保留目标与辅助列；
3. 第 s 层**失去侧向粘连**，开始下落；其他普通格、晶体仍被辅助列托住；
4. 装回普通柱，去掉辅助列。

选中普通格正上方紧接的连续针链也随之下降，其余材料保持原位。

### 构造 F：至少六象限的受控下落

**目的**：把目标第 **s** 层的普通格降到第 **d** 层（`d < s`，且第 **d** 至 **s−1** 层全空），**中途不停在更高的位置**。
沿环用四个连续位置：`针槽柱 N | 目标 A | 辅助柱 B | 碎晶桥柱 E`，其余象限为空。三根辅助柱从地面做到高度 **H**：

| 柱 | 各层材料 |
|---|---|
| N | **第 s 层为针**，其他层 `T` |
| B | **第 d, d+1, …, s−1 层为晶体**，其他层 `T` |
| E | **第 d 层为晶体**，其他层 `T` |

施工顺序：
1. 保留目标原普通柱，接入 B、E；
2. 由 B 接管目标支撑，把原柱换成 N；
3. 选一条半破轴，保留 `N`、`A`、`B`，去掉 `E`（至少六象限的半边容得下三列）；
4. 切口打碎 B 中的晶体通道；**第 s 层的目标普通格与 B 的普通格粘成双格，一起下降**；
5. **B 的第 d−1 层仍在**，故双格停在**第 d 层**；若 `d = 1`，由地面挡住；
6. 交接回普通柱，清除其他辅助材料。

落点由 B 提供支撑，所以目标第 `d−1` 层为空也能停在第 `d` 层。选中普通格上方若紧接连续针链，这段针跟随下降。

> **要点**：B 的晶体只填在 `[d, s−1]`，所以切口打开的是这一段通道，而 B 在 `d−1` 层的普通格正好当"刹车"。

### 构造 G：四象限的单孔环下落

**目的**：把一枚普通格**只降一层**（弱下落会落到更下面，环下落可以在中间停住）。
设目标第 **t, t+1, t+2** 层连续为晶体。选一个空位 **h < t**，要求 **h 与 t 之间只有普通格和空**。
制作满高辅助列 B：**第 h 层为晶体；第 t+1 层为针；其他层为普通格**。

在第 `t, t+1, t+2` 层，目标与 B 组成（B 的 3 格：`T / P / T`）：

```
层 t     : 目标 c    B T
层 t+1   : 目标 c    B P
层 t+2   : 目标 c    B T
```

这个环使上部互相支撑。B 中唯一晶体位于**针以下**，整列连续接地，可以用紧列、普通格和针独立制造。

1. 装入 B，移去原普通柱；
2. 在 B 另一侧接入**仅第 h 层为晶体**、其余为普通的桥柱；
3. 保留目标和 B，半破去掉桥柱，打碎 B 第 h 层晶体；
4. **h 以上、t 以下的普通材料整体下降一层**，上面的环保持原位；**原空位被搬到第 t−1 层**；
5. 换回普通支柱，清除 B。

目标第 h 层为空；碎晶涉及 B 和桥柱中的晶体；目标晶体、窗口以下和晶体环以上的目标材料均保持原位。

单格特例：三连晶下方只有最高的一枚普通格需要移动、且它与三连晶之间全空时，可以反复把它正下方的空位当作 h，每次下降一层直到指定位置。

> 例：`cT..Tccc → cT.T.ccc`，把第 5 层普通格降到第 4 层，第 3 层仍为空。弱下落会落到第 3 层，环下落才能在第 4 层停住。

### 构造 H：四象限的一次顶针批量下落

**目的**：把一组指定下降**安排在一次顶针里**同时完成（这是「顶针次数少」的物理来源）。
所有标记都使用**顶针后**的层号。把计划下降写成 **`s → d`**：普通格将从第 **s** 层降到第 **d** 层，且 **`2 ≤ d < s ≤ H`**。
沿四象限环依次放：`目标 A | 晶体桥柱 B | 满高纯晶体柱 E | 针槽柱 N`。定义两个层号集合：

- **I**：所有下降通道 `[d, s−1]` 的并集；若还要同时碎掉临时晶体，则再加入每个临时晶体段**最上面的一层**；
- **J**：所有下降的**源层 s**。

顶针**前**的辅助件按下面的规则制造（`z = 1, …, H`）：

| 辅助列 | 第 z 层放什么 |
|---|---|
| B | 若 **`z+1 ∈ I`** 放晶体；否则放普通格 |
| E | 放晶体 |
| N | 若 **`z+1 ∈ J`** 放针；否则放普通格 |

**顶针把第 z 层上移到第 z+1 层**，所以辅助件按顶针后的层号对齐——这就是处处出现 `z+1` 的原因。

装配：先保留 A 的普通柱、装入 B；由 B 接管支撑，再换入 E、N。随后**顶针一次**：
1. E 顶端超限，整根晶体柱破碎，**连带删除 B 的全部晶体桥**和相接的临时晶体段；
2. 每个源层 s 的 A、B 普通双格与 N 的针不粘连，沿打开的通道**下降到 d**；
3. 其他目标普通格和晶体继续由 N 支撑；
4. 保留 A、N，去掉 B、E 的余料，再把 N 换回普通柱。

**使用前提**：各下降通道在删晶后全空、源格移动彼此独立；保留的目标晶体与待碎晶体簇分离；每个落点以下的 B 普通段由地面新针或本次保持原位的目标普通／晶体格支撑。

> 构造 D/E/F/G/H 才是「造空位」的真身：**顶针只是搬运工**，真正造空位的是
> 「临时支柱 + 选择性碎晶 + 让某格失去侧向支撑」。我们之前推的「顶针浇灌」只是其中一小块。

## 4. 拼装层：交换链【我们的推导，已验证】

判据层保证「某一列/某一个半边能不能造」，拼装层负责「把零件拼成整图」。

### 4.1 四个带柱半半边的柱位

```
P1 = 内容 [a, a+ls-1]            + 柱 @ (a-1)
P2 = 内容 [a+ls, a+half-1]       + 柱 @ (a+half)
P3 = 内容 [a+half, a+half+rs-1]  + 柱 @ (a+half-1)
P4 = 内容 [a+half+rs, a-1]       + 柱 @ a
                        （全部 mod n；half = n/2）
```

**每个半半边只有一根柱**（概念上可以有两根，交换时只有一根能作为支撑保留，另一根进废料）。

### 4.2 交换前的旋转

让内部切点落到刀口上：

```
P1、P2 各自 顺转 (half - ls)；P3、P4 各自 逆转 rs
交换后转回来：左 逆转 (half - ls)，右 顺转 rs
```

### 4.3 切割与交叉拼接

- 刀口固定在 `n/2`（不是柱子中点）；
- `out1 = A.东 + B.西`（通常废料），`out2 = A.西 + B.东`（通常所需）；
- 合并逐格「左非空取左，否则取右」，重叠时右边内容丢弃；
- 末次交换不需要额外旋转。

### 4.4 成功判据

末次交换的任一输出与目标**旋转等价**即成功；中间步骤必须精确对齐。
方向数 = **(n/2) · (half−1)²**。**轴必须遍历。**

> 早期版本误以为「轴可以被最终旋转等价吸收」。实测（n=6、2 层穷举）有 **11.7%** 的
> 稳定且每列都合法（L）的图形**只在 a ≠ 0 时才成功**。
> 原因：旋转目标会改变**哪两列被切开**，而「旋转等价」只接受产物是目标的某个旋转，
> 不能替代对目标本身不同切法的枚举。

### 4.5 伪代码

```
BuildPillarHalfHalves(target, a, ls, rs) -> (P1,P2,P3,P4)
    P1 ← 保留列 [a .. a+ls-1]           ; 列 a-1      置满层柱
    P2 ← 保留列 [a+ls .. a+half-1]      ; 列 a+half   置满层柱
    P3 ← 保留列 [a+half .. a+half+rs-1] ; 列 a+half-1 置满层柱
    P4 ← 保留列 [a+half+rs .. a-1]      ; 列 a        置满层柱
    P1,P2 ← RotateRight(·, half-ls)
    P3,P4 ← RotateRight(·, -rs)

Exchange(A,B) -> (out1, out2)
    (Aw,Ae) ← Cut(A);  (Bw,Be) ← Cut(B)
    out1 ← Merge(Ae,Bw);  out2 ← Merge(Aw,Be)
```

### 4.6 与论文算法 9 的对应

论文的半边制作流程：

```
两根带柱列 → 调整支柱朝向（目标放第 1、2 列，外柱放第 4、3 列）
          → 以 (4,1)+(2,3) 交换组装
          → 换到 (1,2)+(3,4) 轴，半破去掉两根外柱
          → 目标两列共同下落一次 → Q
```

我们交换链的 P1/P2 正是「一根带柱列」，4.2 的预旋转正是「调整支柱朝向」，末次交换正是「共同下落」。**两者是同一件事的两种写法**，可以合并：`BuildPillarHalfHalves` 负责零件，算法 8 负责判定零件对不对，算法 9 负责下落那一步。

## 5. 求解流程（按 n 分档）

### 5.1 公共前置

```
1. 读 cap = 文档层数，读 n。
2. 每一列做五项条件检查（O(n·L)）。
   有任一列失败 ⇒ 不可制作，直接返回。
3. 之后按 n 分档。
```

### 5.2 n = 2

```
可分  ⟺  左列和右列分别通过孤立列判据（定理 4）
构造：算法 7（拿掉尾部与底针 → 构造 A 做紧列 → 顶针补底针 → 逐格堆叠接回尾部）
      → 两列送入交换
```

### 5.3 n = 4

```
for 轴 in {0, 1}:
    取静态左半边 Ql、右半边 Qr
    if 算法 8(Ql) 接受 且 算法 8(Qr) 接受:
        → 可分
        构造：算法 9 造两个带外框输入 → 交换
        失败
```

算法 8 的两条候选都要试：先 Q 本身（两列都在 S 且 Q 稳定），再联合逆提升。

### 5.4 n ≥ 6

论文给出的是**列级**结论：每一项都通过五项条件 ⇒ 该列可以造成 S（定理 2）。

整图拼装用我们的交换链，需要补一条推论：

> 【推论，待验证】n ≥ 6 时，若目标每一列都通过五项条件，则四个带柱半半边都可以造出来：
> 先把每一列造成 S（定理 2 + 算法 1–3），再用构造 C 的支柱交接把同一段的几列合成一个零件
> （每列连续接地，交换拼装时不会掉落）。

于是：

```
for a in 0..half-1, ls in 1..half-1, rs in 1..half-1:
    造四个半半边（按推论）
    稳定性检查：四片都要稳定（Cut 会塌陷）
    交换两次，回旋
    末次交换，任一输出与目标旋转等价 ⇒ 成功
```

**这条推论是我们自己的，论文只覆盖到「带普通支柱列」。** n ≥ 6 的整图可分性是否还有更强的结论，还没有。

#### 实测覆盖率（n=6、2 层、字母表 `{., T, c}`，531,441 个图形穷举）

```
稳定                        : 440,081
稳定且每列都 L              : 232,425
其中交换链成功               : 230,601  (99.2%)
失败                        :   1,824
只在 a≠0 才成功              :  27,200  (11.7%  ← 轴必须遍历)
```

失败的 1,824 个清一色是**超悬挑**形状，例如 `Cu----------:CuCuCuCu----`
（第 1 层只有第 1 列，第 2 层是横跨 6 列的整条横杆）：横杆是一个整粘连组，被切到任一半边后
都会失去唯一的那根支撑而掉落，所以任何轴都过不了——**它们本身也不是可交换图形**。

### 5.4.1 范围约定：只处理可交换图形

> **本规格暂不处理「不可交换」图形。**
>
> 判定的**第一道门**是「可交换」（= 论文的**可分**）：存在某个朝向使两个静态半边都半破可得
> （n=2/4 用定理 5/6，n≥6 用 §5.4 的推论）。
> 不可交换的图形（如上面的超悬挑）**返回"未覆盖"，而不是"不可制作"**。

穷举结果给出了一个很干净的分离（n=6、2 层、`{., T, c}`，稳定且每列都 L 的 232,425 个图形）：

```
可交换 & 交换链成功 : 230,601
可交换 & 交换链失败 :       0    ← 零反例
不可交换 & 成功     :       0    ← 零反例
不可交换 & 失败     :   1,824
```

即在被测范围内：

```
（每列都 L  ∧  整体稳定）  时，  交换链成功  ⟺  可交换
```

⇒ **「可交换」既必要又充分**，而且它正好就是交换链自身的可行性条件。
所以路线收敛成一条：

```
第 0 道门：每列过五项条件（否则不可制作）
第 1 道门：可交换（否则返回"未覆盖"）
主体：交换链组装（n/2 · (half-1)² 个方向）
零件：按需调用构造 A–H 把列造成 S
```

> 这是**有限范围的经验结论**（n=6、2 层 **和 3 层**都已验证），不是定理。
> 3 层数据：`{.,T}` 穷举 2^18 得 91,708 个合格样本、0 不一致；`{.,T,c}` 随机取样
> 15,307 个合格样本、0 不一致。

### 5.5 复杂度

| 步骤 | 代价 |
|---|---|
| 五项条件（全图） | O(n·L) |
| n=4 的算法 8 | 每条轴 2 个半边 × 2 个候选 × 一次下落 O(n·L) |
| n≥6 的交换链 | `(n/2)·(half-1)²` 个方向 × 约 7 次 `Collapse`，每次 O(n·L) |
| n=20 估计 | 810 个方向 × 7 ≈ 5,700 次塌陷（每次 ≤ 100×20 格），亚秒级 |

**全部判据都是 O(L) 的线性扫描，没有任何按层数或象限数的枚举表。**

### 5.6 rank 解析框架（暂不考虑循环支撑结构）

旧 TMAM 流程（发现 rank / 循环支撑之前）只探索到「顶针一次」，而且 hybrid/deny 只有
4 象限 5 层的特化打表。下面把它抽象成**通用的、带 rank 预算的逆推框架**。

#### 5.6.1 旧流程其实只有三个逆运算

| 旧流程的步骤 | 本质 |
|---|---|
| B 可交换 → 做所有角 → 交换组装 | 终点 `SwapBuild(Y)`（rank 0） |
| 去掉最底层 + 填水晶塔 → C，要求 `顶针(C) = B` | 顶针逆的「D 型」：`PPInv`（花 1 rank） |
| 拆 hybrid（从上往下剥层）→ D，要求 `Stack(D, hybrid) = B` | 堆叠逆 `StackInv`（不花 rank） |
| deny：拆 hybrid + 填塔 → E，要求 `顶针(E)` 再 `Stack(hybrid)` = B | `StackInv ∘ PPInv` —— 递归里自动出现，不用单列 |
| 拆到倒数第二层仍不可交换 → 不可制作 | 预算耗尽 → 应报「未覆盖」而不是「不可制作」 |

#### 5.6.2 三个逆运算的定义

**(a) 终点 `SwapBuild(Y)`**：`Y` 可交换 ⇒ 做所有角 + 交换链组装（§4）。

**(b) 堆叠逆 `StackInv(Y)`**：找 `(D, H)` 使 `Stack(D, H, cap) = Y`。
`Stack` 的语义是「D + 一空层 + H → 塌陷 → 截到 cap」，所以 `H` 就是"后来落下来的那部分"。

**hybrid 的通用定义**（替代打表）：

```
H 的候选 ≠ "不稳定的格"
H 的候选 = 可独立制作、且能堆回去的块：
    (1) H 自身必须可制作（稳定 + 能由交换链造出来，或递归可解）
    (2) Stack(D, Y∖H) 必须恰好等于 Y
    (3) 剩下的 D 仍需单独判可交换
```

> **⚠️ 早先的错误写法**：曾用「不稳定半边的落下组」当 hybrid 候选。
> 这是反的——落下的组恰恰是**站不住**的格，它们无法独立制作（一枚悬空的 `T` 造不出来），
> 正是不满足"可拆"前提的那一部分。真正的 hybrid 是**能自己站住、但破坏了整体可交换性**的块
> （典型是一枚顶针、或一层横条）。

**hybrid 的搜索是带回溯的**：同一层可能有多处可拆（二择），拆错就要退回来；
老实现把它压成了 4 象限 5 层的特化表，正是因为没有通用的选择准则。

**拆顶针的默认规则**（老流程的约定）：

- 默认「一个顶针可拆就拆」；
- **例外：如果该顶针左右存在晶体，则该顶针不能拆**——拆了水晶塔下不来；下来了会碰到原生晶体；
- 也不能让它「下到倒数第三层」——那样该角不合法；
- 因此这种顶针要**还回去**（deny 分支的核心动作）。

也就是说，**拆/还都由「水晶塔能否合法落地」来决定**，而不是由「拆掉后是否更稳」决定。

**(c) 顶针逆 `PPInv(Y)`**（含水晶塔）：

```
必要条件：Y[0] 只含 P/空，且 Y[0][c] = P ⟺ Y[1][c] 非空
主解    ：X[j] = Y[j+1]   (j = 0..L-2)      ← 前驱唯一（差一个被丢弃的顶层）
自由部分：X[L-1]  = 水晶塔
```

**水晶塔**是这步的灵魂（对应旧流程的「填水晶塔 + 去掉最底层」）：

**顺序：先填塔，再去掉最底层。**（先去底层会让中间结构失去支撑，填塔就无从对齐了。）

1. 从 `X[L-1]` 开始往下蔓延；
2. 必须**连通**（顶针时整块一起碎）；
3. 必须包含至少一个 `X[L-1]` 的格——那格会被顶针顶出 cap，从而触发整块碎裂；
4. **不能 4-连通到必须保留的原生晶体**（否则会把它们一起炸掉）；
5. **尽可能填满**所有可填的格——填得越多支撑越足，`C` 越可能可交换；
6. **填完必须保持每一列的角合法**（五项条件）——塔格也是格子，会把非法列带进来。

于是：`C`（带塔）可交换、可造；`顶针(C)` 时塔被炸掉，被塔撑住的格落到位，正好得到 `B`。
这正是「填塔、再去掉最底层」的含义。

**填充有两种模式**（这一步还要细分）：

| 模式 | 何时用 |
|---|---|
| **直接填充** | 闭式逆 `X[j] = Y[j+1]` 的底行已经满足收据条件 |
| **抬升块后填充** | 底行的块挡住塔的路径 / 收据行不满足 ⇒ 先把这些块**抬升一层**，再填塔 |

**判定准则（收据行）**：

```
X[0][c] 非空  ⟺  Y[0][c] = P
```

闭式逆给出的 `X[0] = Y[1]` 往往不满足这一条（`Y[1]` 的非空列与 `Y[0]` 的针列不一定重合）。
抬升就是把 `X[0]` 里"不该在这里"的块挪上去一层，让它们的原位置空出来给塔；

> **已验证的例子**（§5.6.2.2 的图形）：
> `Y[0] = .PPP`（针在 2,3,4 象限），闭式逆得 `X[0] = [T,P,.,T]` ✗；
> 把第 1、4 象限的两块抬升一层、塔填满第 3 象限后，`X[0] = [.,P,c,c]` ✔，
> 此时 `顶针(X) = D` 成立，且 `X` 可交换。

#### 5.6.2.1 已跑通的 claw 例子（4 象限 3 层）

目标（顶层在上，`c`=晶体 `T`=普通 `P`=顶针 `.`=空）：

```
L3  c T P T
L2  P . P .
L1  P . P .
```

这个图形**不**可交换（轴 0 右半不稳，轴 1 左半不稳）——两个悬空 `T` 分别只靠对面的晶体支撑，
任何一刀都会切断其中一侧。

正确的分解是「拆掉 (L3, 第 3 象限) 的那枚顶针」，而不是拆那两个 `T`：

```
H  = ----P---                     一枚顶针，可独立制作
D  = Y 去掉 H                     （仍不可交换）
X  = D 顶针的逆 + 填水晶塔         ← 可交换 ✔
     L3  . . c c
     L2  c T c T          （塔 = (L3,2)(L3,3)(L2,2) 三颗晶体，连通、含顶层、
     L1  P . P .            且不碰原生晶体 (L2,0)）
```

实测（`ShapeEditor.Core`）：

```
X 稳定 = True，X 可交换 = True（轴 0 两半都稳）
顶针(X) == D  : True
堆叠(D, H) == Y : True
```

⇒ **完整路径**：用交换链造 `X` → 顶针 → `D` → 把 `H` 堆上去 → `Y`（rank 1）。

两点说明：

- 塔里的 `(L2,2)` 是必须的：它支撑 `(L2,3)` 那枚 `T`，而 `(L2,3)` 是 `D` 的原生格、不能动；
- `(L3,1)` 其实也能填（与塔相邻、会一起碎、且列合法），"尽可能填满"应该把它也填上——
  我上面演示的版本留空了，仍然成立，但不是最满。

#### 5.6.2.2 二择例子（4 象限 5 层，已实测）

```
短代码：--P-P-P-:CuP---Cu:--P-CuCu:cuP---Cu:cuCu----

L5   c  T  .  .
L4   c  P  .  T
L3   .  P  T  T
L2   T  P  .  T
L1   .  P  P  P
```

第一象限有两个晶体（`L4`、`L5`），它们**有两个支撑方向**：`L5` 靠第二象限的 `T`，`L4` 靠第四象限的 `T`。
所以可以拆第二象限的 `T`，也可以拆第四象限的 `T`，但**不能两个都拆**。

实测（`ShapeEditor.Core`）：

| 变体 | 稳定 | 可交换 |
|---|---|---|
| 原图 | ✔ | ✘ |
| 拆 (L5,第二象限) 的 `T` | ✔ | ✘ |
| 拆 (L4,第四象限) 的 `T` | ✔ | ✘ |
| **两个都拆** | **✘ 不稳定** | ✘ |

⇒ 「两个都拆」会直接崩掉，这一条**可以就地判定**；但「拆哪一个」两个变体都还没变成可交换，
**真正的判别发生在下游的水晶塔/顶针阶段**。

这就是为什么「一次选对拆的方向」在 4 象限 5 层要打表：那张表实际编码的是**下游的可解性**。
对任意层任意象限，只能靠**回溯**——先按启发式选一个方向，走到死路再退回来换另一个。

**后续两步（已实测）**：

```
D = --P-P-P-:CuP---Cu:--P-----:cuP-----:cuCu----     （拆完，仍不可交换）

X = --P-crcr:CuP-crCu:cuP-cr--:cuCucr--:----cr--     （抬升块 + 填塔）
    稳定 ✔  可交换 ✔  顶针(X) == D ✔
```

逐列对比 **`X` vs 闭式逆 `X₀`（`X₀[j] = D[j+1]`）**（底→顶）：

```
col0: X₀ = T . c c        X = . T c c      ← T 抬升一层
col1: X₀ = P P P T        X = P P P T      （同）
col2: X₀ = . . . .        X = c c c c c    ← 塔占满整列
col3: X₀ = T . . .        X = c T . .      ← T 抬升一层，L1 让给塔
```

**为什么要抬升**：收据行 `X[0][c] 非空 ⟺ D[0][c] = P`。
`D[0] = .PPP`，而闭式逆的 `X₀[0] = D[1] = [T,P,.,T]` 会在第 1、4 象限凭空多出针、第 3 象限缺针；
把这两块抬升一层、让塔填进第 3 象限（及第 4 象限的底格）后，`X[0] = [.,P,c,c]` 才满足收据条件。
抬上去的块最终靠塔碎裂后的下落回到原位——这就是「先撑住、再炸掉让它掉回来」。

#### 5.6.3 框架

**流水线（六个阶段）**

```
Stage 0  前置检查      n 为偶数、cap = 层数；每列过五项条件（不过 ⇒ 不可制作）
Stage 1  分层          T → (A, B)：A = 最高晶体上方的非空层，B = 晶体及其下方
Stage 2  求解核心      R ← SolveCore(B, rank ≤ 3)
Stage 3  组装          路径 ← R，再堆叠 A
Stage 4  回放校验      用真实物理逐步验证（顶针/堆叠/交换）
Stage 5  输出          Recipe 节点链 / 未覆盖 / 不可制作
```

**数据结构**

```
Recipe :=
    Exchange(Shape)                  # 交换链子路径（rank 0，已定稿）
  | Pin(Recipe)                      # 先造内层，再顶针
  | Stack(Recipe, Block)             # 先造内层，再堆叠一个"可制作块"
  | Stack(Recipe, Tail)              # 最后堆叠尾部 A

Block := { Shape, Recipe }           # hybrid 必须自带制作路径（这就是"可拆"）
```

**核心循环**

```
SolveCore(Y, budget):
    if 列(Y) 有不合法: return 不可制作            # 唯一的"不可制作"
    if Swappable(Y): return Exchange(Y)          # rank 0 终点

    # ① 顶针逆（花 1 rank）
    if budget > 0:
        for C in TowerFill(Y):                   # 直接填充 / 抬升块后填充  【规则待定】
            if 顶针(C) == Y:
                r ← SolveCore(C, budget - 1)
                if r.ok: return Pin(r)

    # ② 拆 hybrid（不花 rank，格数严格下降）
    for (D, H) in HybridStrips(Y):               # 可制作块 + 二择回溯        【规则待定】
        if Stack(D, H) == Y:
            r ← SolveCore(D, budget)
            if r.ok: return Stack(r, H)

    return 未覆盖                                 # 不是"不可制作"
```

**接口契约**

| 接口 | 契约 | 状态 |
|---|---|---|
| `AngleLegal(shape)` | 五项条件（§2.1） | ✅ 已定稿 |
| `Swappable(Y)` | ∃轴：两个静态半边半破可得（n=2/4 用定理 5/6；n≥6 用交换链自检） | ✅ 已定稿 |
| `Exchange(Y)` | §4 交换链（`(n/2)·(half−1)²` 个方向） | ✅ 已定稿 |
| `TowerFill(Y)` | 枚举 `C`，使 `顶针(C) = Y`、`C` 稳定、每列合法 | ⏳ 两种填充模式的判定规则待定 |
| `HybridStrips(Y)` | 枚举 `(D, H)`，`H` 可制作、`Stack(D,H) = Y` | ⏳ 可拆性 + 二择规则待定 |
| `Replay(recipe)` | 逐步跑真实 `ShapePhysics` | ✅ 已定稿 |

**硬约束（每个候选项都必须过）**

1. 每个中间形状**稳定**；
2. 每个中间形状**每列过五项条件**（填塔尤其容易破这条）；
3. 每个等式用**真实物理**验证：`顶针(C) == Y`、`Stack(D,H) == Y`；
4. Stage 1 的 `Stack(B, A) == T` 必须成立，否则分层方式不对。

**终止性**

- `Pin` 分支：`budget` 用尽即止（≤ 3，TMAM 的结论），高度不变；
- `Stack` 分支：`|H| ≥ 1`，总格数严格下降；
- `TowerFill` / `HybridStrips`：有限枚举（受角合法性与高度约束）。

**结论分级**

| 情况 | 结论 |
|---|---|
| 某列不合法 | **不可制作**（唯一的否定判据） |
| 所有分支失败 / 预算耗尽 | **未覆盖** |
| 找到路径 | 可制作 + 节点链 |

**旧流程 → 新框架**

| 旧流程 | 新框架 |
|---|---|
| 层初始化 A/B | Stage 1 |
| B 可交换 → 做所有角 → 交换 | `Exchange(B)` |
| 去底层 + 填塔 → C → `顶针(C)=B` | `TowerFill` + `Pin` |
| 拆 hybrid → D → 堆叠 | `HybridStrips` + `Stack` |
| deny（拆 + 塔 + 顶针 + 堆叠） | 递归里自然出现，不必单列 |
| 拆到倒数第二层仍不可交换 → 不可制作 | 改为 **未覆盖** |

> **两个待定的接口不阻塞框架落地**：`TowerFill` / `HybridStrips` 可以先做保守版本
> （只试"直接填充"、只拆"单个顶针"），框架其余部分照跑；之后再替换成更强的规则。
