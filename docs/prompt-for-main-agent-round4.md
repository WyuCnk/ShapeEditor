## 任务 1：把 M1（弱落次数）设为路线选择的第一目标

**当前问题**：路线选择顺序是「能过就用」，不是「弱落更少就用」。

**改成**：

```
对每个角，收集所有可行路线（H 一次顶针 / G·D 碎晶 / 算法6 / 算法5 / 多刀）
逐条跑完 Gate 四条
按 M1→M7 字典序选最优（见 metrics 文档 §1）
```

**注意**：不要为了指标牺牲覆盖率——3–9 层失败数必须仍为 **0**。

## 任务 2：撤销「`t[1]=='T'` 不进构造 H」的硬短路

第三轮加的短路（`t[1]=='T'` 直接走切割/弱落）**已被反例推翻**：

```
目标 T.T.c（t[1]='T'）
A = .TTc.   B = TcT..   E = ccccc   N = PPPT.
半破/顶针：Pin → T.T.c ✔（实测）
```

⇒ 改成**软策略**：仍然先试 H（成本低，一次回放就能判），H 不过再走切割/弱落。
（短路带来的耗时收益保留：H 试一次失败就换，不要重试变体。）

## 任务 4：弱落「下界」判定

有些角**必须**多次弱落（用户确认存在）。请为每个含弱落的列标注：

```
· 该角至少需要几次弱落（下界）
· 实际用了几次
· 若实际 > 下界 ⇒ 记为「待优化」，列进报告
```

下界怎么估：`弱落下界 ≥ 该角需要「单独移动一格」的次数 − 一次顶针能覆盖的下降数`。
拿不准就写「未定」，不要瞎估。
